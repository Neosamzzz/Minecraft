# FTB 太阳系任务定稿表

本表用于制作、审阅和调整 FTB 任务，列出采用的任务、游戏内文字、完成目标及编排关系。文档供制作时查看和确认；游戏内任务书负责增加游玩目标与乐趣。

后期候选内容见[预备稿](ftb-quest-manuscript.md)，玩法依据见[物品核对](quest-item-notes.md)及[星球玩法详解](../../docs/research/planet-gameplay-guide.md)。保留原编号便于对照，表格行序不代表强制完成顺序。

## 采用范围与写法

- 六章采用 **44 个独立任务**；原太阳系 60 项中的另外 16 项并入相关说明或不再单独编排，取舍见文末。
- 保留有辨识度的标题。正文有必要再写，主要补充目标用途、整合包特有的变化或可选玩法；不套用“用途／操作／提示”，不添加冒险旁白或基础教学。
- “—”表示不另写正文，只保留标题与目标；不是游戏内占位文字。编排和制作备注仅供作者使用。
- 目标以获得物品、实际抵达和有效击杀为主，不配置奖励。物品数量默认 1，不消耗，不限定制作、交易或采集来源。
- 常规章节六章、44 项；16 项兼容定义保留原任务和条件 ID，关闭完成提示。

## 转配置时核对

- 采用节点继续沿用原任务和条件 ID；本表编号不重排，不复用并入节点的编号。
- “并入说明”不代表合并后台条件，也不意味着提高物品数量或增加前置锁。
- 原 60 项的检测定义全部保留。并入项移至兼容归档章，避免删除定义后旧条件记录在下次保存时丢失。
- 形状、大小和错位分叉已落实；44 项文字与本表逐项核对一致。此前已逐章查看显示，最后月球车支线调整仅静态核对，未重新加载验收。
- F06 之后的系外、九／十阶、开普勒、能源核心与 H01“这是...”继续留在预备稿；既定路线与发现后揭示原则不变，尚未部署。

## 编排与表达

- 整体保持简单，接近 MC 原版进度的轻巧感：标题有一点趣味和画面感，说明简短、自然、实用。文案根据具体玩法和景观写出差异，避免反复套用“去看看”“带回来”或逐阶更换数字；可用轻巧的梗与意外感，事实和操作含义仍须清楚。
- 目标以获得物品、抵达地点、击败明确存在的敌人为主；不把出发检查清单拆成一串任务。标题允许自然的玩笑和熟悉的梗，保留登月标题“我的一小步，人类一大步”。
- 趣味主要来自任务选取、标题、发展节点与自由探索；日常正文不添加冒险旁白，不额外设计职业、等级或技能树。轻量主线设定继续保留。
- 围绕有意义的玩家行动组织内容；正文有需要再写，不硬凑每项说明。普通加工和重复准备并入相关备注，不把每个合成零件都拆成任务。
- 从 GC / GS / EP 选择载具、移动工具、供氧设备、补给和特殊样本作为可选支线，复用已有物品，依据见[物品核对](quest-item-notes.md)。不强迫全收集，不因物品有类名或注册就认定生存获取链可用。
- 区分必要发展与可选探索，允许并行和分支；前置关系应反映实际需要，不仅为了画出连线而增加门槛。
- 不设计或配置任务奖励，也不以奖励推动节奏。“收获”指玩法能力、新材料用途和探索空间等游戏本身的进展。此约定不要求移除模组原有的地牢战利品等机制。
