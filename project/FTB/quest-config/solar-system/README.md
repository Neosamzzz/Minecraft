## 原 16 项的兼容归档

原配置的 60 个任务、60 个条件定义均保留。定稿表中被合并或不再单列的 16 项移入 `6a01ff00` 章节，设置 `always_invisible=true`；这些任务设为可选并关闭完成提示，不出现在普通章节栏中。编辑或直接定位历史定义仍属维护用途，不将隐藏章节当作访问权限控制。

后台日志应为 **7 章、60 任务、60 条件、0 奖励**；普通章节栏为 **6 章、44 项**。两种数量分别描述注册数据和玩家编排，不代表重复加载。

源码读取团队数据时只接收已注册任务的条件 ID，保存时按当前注册数据重写。因此不直接删除旧定义，不清除或合并团队数据；兼容章保留原 ID 和检测规则。归档条件仍可能正常记录进度，但不会弹出这些任务的完成提示。

## 安装与恢复

`normal/` 是配置源，目标为实例实际加载的 `config/ftbquests/<模式>/`；默认模式是 `normal`，游戏规则 `questfile` 或 PackMode 可改变目录。联机任务定义由服务端维护，客户端需要匹配的模组。

新实例可安装整个 `normal/`。从本项目旧 60 项更新时，必须将那 16 个任务文件从原章节目录移至兼容章；不能只叠加新目录而在旧位置留下同 ID 定义。原位置记录在 `manifest.json` 的 `archived_nodes[].original_chapter`。对不相关的已有任务书先核对章节索引和 ID，不直接覆盖。
