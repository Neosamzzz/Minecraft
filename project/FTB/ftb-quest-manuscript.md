# FTB 任务预备稿

本稿维护四阶调整至特拉尔斯-9终章的完整任务内容，除 G05、G09 外已转为配置部署；后续调整先改本稿再同步配置。地球、月球与火星两章沿用定稿表，已部署的六章以[定稿表](ftb-quest-content.md)和[配置](quest-config/solar-system/README.md)为准；本稿不重复保存已部署文案，采用后同步定稿表与配置。关联 [Issue #12](https://github.com/Neosamzzz/Minecraft/issues/12)。

标题取自现实航天史的计划、任务与地面口令：水手、海盗、旅行者、伽利略、卡西尼、新视野、朱诺、黎明，以及总装、认证、试车、着陆确认一类工程节点。标题只承担成就语气，目标与判定写在任务条件里。编号 N／G／I／J／H 是文稿编号，不是配置 ID；九／十阶为内部代号，代码沿用 9／10。

内容基调见[内容方向](ftb-quest-content.md)，物品依据见[任务关键物品核对](quest-item-notes.md)，实现与部署状态以[物品线说明](../NewEarth/items/README.md)为准。
