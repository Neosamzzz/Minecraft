# 航天制造与太阳系整合路线手稿

## 整合原则

- 做深度魔改整合包，以 GC／GS 的主要制造、加工、装备与防护体系为基础，按需要调整模组、配置和配方。
- 定稿 config 作为固定玩法的一部分随版本交付，不支持替换配置切换模组组合；后续按正式配置逐项维护，禁止原版、旧备份或实例配置整份覆盖，执行[根 README 的固定配置交付约定](../../../README.md#固定配置交付约定)。
- 根据保留星球的实际矿物与特色产出设计新配方；不沿用 EP 原七阶板材链，也不先规定部件再为其补造资源。七阶制造集中使用六阶及以前可取得的太阳系资源。
- 保留的材料必须接入实际加工、制造或升级，尤其保证后段星球特色材料有用途；可分配到七阶、九阶与十阶，避免删除旧装备后留下用途空缺。机器只要仍有加工、供电、供氧、精炼、加注、净水等实际作用就保留，功能相近不作为裁剪理由；具体加工改造另行设计。
- EP 提供选用的地表、矿物、Boss、地牢、结构及适合复用的机器和表现素材。EP 普通工具、武器、护甲与防护装备取消注册及制造。材料和机器按制造用途保留。
- 原 EP 各阶火箭、专用部件与板材、旧图纸及制造路线先整体退出，含原七阶和电力十阶；按新火箭设计选择性复用，不预先锁定旧部件。模型、贴图等作为候选素材；矿物、通用材料和有用机器分别保留。
- 主星、卫星归属一起整理，但不要求同一体系全部使用同一模组：允许 GS 卫星挂到 EP 主星。不同实现的矿物、环境和奖励不能混写。
- 环境采用 GS 普通／轻型宇航服与 GC／GS 温控体系。土星体系处于五阶阶段，海王星体系、冥王星和 Eris 处于六阶阶段；防护材料在出发前取得。

## 路线手稿

| 阶段 | 探索与准备 | 解锁与制造结果 |
| --- | --- | --- |
| 地球至三阶 | GC 后勤、月球、火星、小行星带、金星；GS 水星镁、谷神星白云石；探索 EP 水星 | 月球／火星延续基础图纸；EP 水星地牢取得 GS 四阶图纸，制造 GS 四阶 |
| 四阶探索 | EP 木星采火山岩、钯和宝石；GS Io 取得火山石与离子引擎，其他木卫星按资源价值探索 | EP 木星地牢取得 GS 五阶图纸，制造 GS 五阶；EP 火山锭与 GS 火山石是两种材料 |
| 五阶探索 | EP 土星地牢；GS 土卫二晶体及温控准备；GS 天卫五继续按五阶阶段保留 | EP 土星取得 GS 六阶图纸，作为六阶图纸唯一来源；制造 GS 六阶 |
| 六阶探索与加工解锁 | 六阶支持离子改装；探索海王星、冥王星、Eris，以及保留的其他六阶太阳系内容；采集实际原料 | 海王星给制造台图纸；冥王星给七阶图纸；Eris 给亚光速引擎图纸 |
| 天王星探索分支 | 采水晶与白色宝石，保留 Boss 地牢 | 原七阶图纸替换为一件特殊道具的图纸；道具和天王星主星门槛待定，不抢占冥王星的七阶解锁 |
| 七阶制造与远航准备 | 材料制造台加工复合板、隔热衬层、航电与连接组件；装配机制造四类配件；旧引擎投入下一代引擎制造 | 冥王星图纸解锁七阶总装，亚光速动力支持常规系外；配方草案见Recipe Studio，主引擎配方与安装方式待定 |
| 系外及后续 | 比邻星、巴纳德 C／C1、鲸鱼座 τ f 等资源探索，随后多人飞船、开普勒及最终升级 | 以等离子引擎制造九阶前往开普勒；取得材料后以黑洞引擎制造十阶前往终章，均未实施 |

四、五、六阶图纸分别只能从 EP 水星、木星、土星地牢获取。旧 GS 许可和制造路径必须与新的图纸解锁实际衔接，不能只换地牢里一件物品。七阶制造台及引擎升级所需材料不能形成自我依赖。

七阶集中消耗六阶探索产物，承担太阳系阶段的备料与加工收束。主体以六阶结构为参照，提高既有材料链和外太阳系产物的投入。

## 七阶制造草案

材料制造台承接海王星图纸，使用七阶以前的材料制造，建成后重复加工。四类中间件分别承担以下用途：

| 中间件 | 资源分工 | 用途 |
| --- | --- | --- |
| 钨基复合板 | 六阶强化板延续原GS材料链；冥王星钨配合钯与EP火山锭 | 鼻锥、箭身、助推器与尾翼的主体结构 |
| 隔热衬层 | EP碳、GS未知晶体与塑料，配合海王星／海卫一的冻结氮 | 鼻锥、助推器与尾翼的隔热结构 |
| 深空航电组件 | GS晶圆配合EP水晶、白宝石晶圆、海王星蓝宝石与锌 | 箭身控制组件 |
| 锌基连接组件 | 海王星锌配合GC铜板与GS空白模块 | 箭身与助推器的连接部件 |

配件沿用GS装配机的制造形式，主体沿用GS火箭装配机的总装形式。主引擎保留独立槽位，装配方式、消耗和航行资格随引擎路线确定。冥王星七阶图纸、海王星制造台图纸分别接入对应制造解锁。

[Recipe Studio工程](recipe-studio.json)维护配方数量、产量、槽位和用量测算。该草案覆盖主体制造与首次增建制造台。制造参数沿用可复用的机器规则，主引擎单独接入。

## 地牢奖励与引擎迭代

| 地点 | 新关键奖励 | 边界 |
| --- | --- | --- |
| EP 水星 | GS 四阶火箭图纸 | 唯一获取来源，替换原 EP 四阶图纸 |
| EP 木星 | GS 五阶火箭图纸 | 唯一获取来源，替换原 EP 五阶图纸 |
| EP 土星 | GS 六阶火箭图纸 | 唯一获取来源，替换原 EP 六阶图纸 |
| EP 天王星 | 特殊道具图纸 | 具体道具待定，替换原 EP 七阶图纸 |
| EP 海王星 | 特殊制造台图纸 | 替换原 EP 八阶图纸；先造台，之后重复加工 |
| EP 冥王星 | 七阶火箭图纸 | 替换原 EP 九阶图纸 |
| EP Eris | 亚光速引擎图纸 | 替换原 EP 十阶图纸；电力十阶图纸等旧奖励也需审查 |
| GS Io | 离子引擎 | 引擎奖励仅保留离子，移除直接取得亚光速引擎的入口 |

引擎采用同一条路线迭代升级，旧代引擎作为下一代的投入。路线确定为离子→亚光速→等离子→黑洞：六阶安装离子前往 Eris，取得亚光速图纸；七阶阶段使用亚光速支持常规系外航行；等离子引擎用于制造九阶多人飞船、前往开普勒；黑洞引擎用于制造十阶飞船、前往终章。各代配方和数量待定，九阶不能依赖开普勒原料；黑洞引擎以等离子引擎为基础制作。等离子引擎完成时保留一个可被玩家注意到的空核心位置；这个位置用于容纳开普勒五色钻石与铂制品制作的最终能源核心，取得核心后补全这一处，承接黑洞引擎与十阶升级。空位不妨碍等离子阶段的正常功能和九阶前往开普勒；具体装配交互、配方与核心消耗或保留方式待定。原GS改装台支持安装、拆卸并返还已有引擎，NewEarth已接入六阶离子改装。七阶装配沿用可复用的引擎接口。

黑洞引擎完成演出：在制作台装上引擎并完成最终装配后，制作台炸开，原处留下完成的黑洞引擎。炸开的制作台本体属于这次制作演出的结果，不波及周围方块，也不造成任何伤害；不得让爆炸摧毁或丢失引擎成品。该演出在十阶阶段实现。

## 表现与后期候选

- EP七阶模型作为放大与结构改造候选；九／十阶模型作为后续载具素材候选，造型、比例和细节继续调整，也可重做。
- 十阶尾焰以EP电力十阶效果为基础小改。普通／电力十阶均调用GC升空与点火粒子；喷口位置、粒子尺度与新模型共同适配，动力规则沿引擎路线确定。
- 十阶控制面板制造路线参考GS信息面板的界面风格。
- 后期统一为九阶基础多人飞船、十阶最终升级；十阶依靠黑洞引擎并满足最终能源核心条件前往终章，具体制造方式待定。

## 图纸解锁要求

冥王星七阶图纸必须接入实际地牢奖池、GS 许可和制造台；检查普通与特殊奖池、重复获取及旧制造入口，确保首次七阶不依赖系外材料。

地牢适配必须覆盖以下分支：

- EP 水星四级池与 GS 谷神星共享，EP 木星五级池与 GS Io 共享；按具体地牢或 Boss 替换奖励，避免新路线专属图纸出现在 GS 地牢。
- 冥王星太空人 Boss 与默认苦力怕 Boss 均须奖励七阶图纸，保持钥匙、宝箱等级和解锁页面可用。
- 检查天王星旧七阶图纸和直接合成等生存绕过入口；完整启动后实测冥王星开箱取得与解锁。
