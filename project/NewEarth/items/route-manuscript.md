# 航天制造与太阳系整合路线手稿

## 整合原则

- 做深度魔改整合包，以 GC／GS 的主要制造、加工、装备与防护体系为基础，按需要调整模组、配置和配方。
- 定稿 config 作为固定玩法的一部分随版本交付，不支持替换配置切换模组组合；后续按正式配置逐项维护，禁止原版、旧备份或实例配置整份覆盖，执行[根 README 的固定配置交付约定](../../../README.md#固定配置交付约定)。
- 根据保留星球的实际矿物与特色产出设计新配方；不沿用 EP 原七阶板材链，也不先规定部件再为其补造资源。七阶制造集中使用六阶及以前可取得的太阳系资源。
- 保留的材料必须接入实际加工、制造或升级，尤其保证后段星球特色材料有用途；可分配到七阶、九阶与十阶，避免删除旧装备后留下用途空缺。机器只要仍有加工、供电、供氧、精炼、加注、净水等实际作用就保留，功能相近不作为裁剪理由；具体加工改造另行设计。
- EP 提供选用的地表、矿物、Boss、地牢、结构及适合复用的机器和表现素材。EP 普通工具、武器、护甲与防护装备取消注册及制造。材料和机器按制造用途保留。
- 原 EP 各阶火箭、专用部件与板材、旧图纸及制造路线先整体退出，含原七阶和电力十阶；按新火箭设计选择性复用，不预先锁定旧部件。模型、贴图等作为候选素材；矿物、通用材料和有用机器分别保留。
- 主星、卫星归属一起整理，但不要求同一体系全部使用同一模组：允许 GS 卫星挂到 EP 主星。不同实现的矿物、环境和奖励不能混写。
- 环境采用 GS 普通／轻型宇航服与 GC／GS 温控体系。土星体系处于五阶阶段，海王星体系、冥王星和 Eris 处于六阶阶段；防护材料在出发前取得。

## 六阶探索与七阶制造

### 制造台与材料

天王星图纸解锁引擎升级台，海王星图纸解锁材料制造台。两台设备均使用太阳系阶段原料制造，建成后重复加工。

材料制造台加工以下四类中间件：

| 中间件 | 资源分工 | 用途 |
| --- | --- | --- |
| 钨基复合板 | 六阶强化板延续原GS材料链；冥王星钨配合钯与EP火山锭 | 鼻锥、箭身、推进器、助推器与尾翼的主体结构 |
| 隔热衬层 | EP碳、GS未知晶体与塑料，配合海王星／海卫一的冻结氮 | 鼻锥、助推器与尾翼的隔热结构 |
| 深空航电组件 | GS晶圆配合EP水晶、白宝石晶圆、海王星蓝宝石与锌 | 箭身控制组件 |
| 锌基连接组件 | 海王星锌配合GC铜板与GS空白模块 | 箭身与助推器的连接部件 |

### 配件与总装

配件沿用GS装配机制造，七／九／十阶主体在星际组装台总装；七阶也可沿用GS火箭装配机。总装必需鼻锥×1、箭身×2、推进器×1、助推器×2、尾翼×2及七阶火箭图纸×1。中央动力槽另投入亚光速引擎×1，合成成品保留亚光速引擎状态。冥王星七阶图纸、海王星制造台图纸分别接入对应制造解锁。

七阶物品模型采用改造后的EP七阶外观；实体仍沿用GS六阶表现。配方测算使用[Recipe Studio工程](recipe-studio.json)。

### 离子与亚光速引擎

六阶安装Io取得的离子引擎后前往Eris，取得亚光速引擎图纸。在引擎升级台以离子引擎＋亚光速引擎图纸加工亚光速引擎，供七阶总装使用。

### 引擎升级台

引擎升级台不需要供电。第一输入槽固定放引擎，第二输入槽固定放对应升级材料，输出槽只取出新引擎；每次各消耗一个输入，输出一个成品。容器、界面与JEI使用相同的双输入布局，不设电池槽、能量条或电力接口。加工等待时间仍为 200 tick，是否要改待定。

| 第一输入槽 | 第二输入槽 | 输出槽 |
| --- | --- | --- |
| 离子引擎×1 | 亚光速引擎图纸×1 | 亚光速引擎×1 |
| 亚光速引擎×1 | 等离子引擎图纸×1 | 等离子引擎×1 |
| 等离子引擎×1 | 最终能源核心×1 | 黑洞引擎×1 |

### 座椅与七阶配件备料

七阶鼻锥包含GC座椅×1。座椅沿用原生工作台配方：压缩钢×5＋压缩铁×1→座椅×1，摆法为右列上中两格放钢板、中央放铁板、底行放三块钢板。

一套七阶配件共消耗钨基复合板×31、隔热衬层×5、深空航电×2、锌基连接组件×4，以及原配方中的座椅、氧气罐、密封导线、燃料模块等部件。按批量加工需制作复合板×32、隔热衬层×6，分别余1。座椅加工、鼻锥制造、配件总装与中央亚光速引擎在Studio分别展示。

### 图纸接入

四至六阶地牢直接掉落 GS 火箭模块许可：水星为四阶（meta 8），木星为五阶（meta 9），土星为六阶（meta 10），总装沿用 GS 原配方。地牢来源保持不变。各星球专属图纸按地牢维度分配，覆盖冥王星太空人与默认苦力怕Boss；EP水星与GS谷神星、EP木星与GS Io的共享奖池分别处理。

## 七阶系外探索与九阶制造

### 资源与材料

九阶制造以巴纳德C的紫木与树脂为主要特色原料，形成紫晶材料与新晶圆两条加工分支。巴纳德C1保留缟玛瑙的原有现代晶圆配方，作为可选加工路线。其余原料、加工设备与通用部件沿用GC／GS及现有七阶体系。

新增材料分为紫晶结构材料与复合部件；电子材料复用一件闲置EP晶圆。具体用量与产量随配方确定：

| 材料层级 | 加工关系 | 制造用途 |
| --- | --- | --- |
| 紫晶碎片 | 巴纳德C紫木原木在熔炉烧制获得，替换对应木炭产出 | 特殊紫晶锭的原料 |
| 特殊紫晶锭 | 紫晶碎片＋巴纳德C树脂，在现有材料制造台（特殊合成台）加工 | 九阶结构与机械配件原料 |
| 紫晶锭板 | 特殊紫晶锭加工为板材 | 船体、舱段与承力结构 |
| 紫晶晶圆 | 特殊紫晶锭×1＋巴纳德C树脂×2＋红石×1＋GS现代晶圆×1，在GC电路制造机加工；产量×3 | 九阶航电、控制与复合部件；复用EP钻石晶圆 |
| 紫晶复合组件 | 紫晶锭板、紫晶晶圆与锌基连接组件加工 | 九阶箭身、推进器与控制面板的集成组件 |

烧制、复合与板材加工复用现有熔炉、材料制造台及压缩设备。新晶圆配方中，特殊紫晶锭放在原钻石位，两份树脂放在上下硅片位，红石位保持红石，GS现代晶圆放在右上催化材料位。复用的EP晶圆需替换旧生产配方、名称与说明。

缟玛瑙保留原配方：钻石×1＋缟玛瑙×2＋红石×1＋GC高级晶圆×1→GS现代晶圆。现代晶圆的其他来源保留，缟玛瑙采样作为可选探索目标。

比邻星 b 作为可选探索节点，保留现有景观、生态、水体与呼吸规则。鲸鱼座 τ f 不另做支线。

### 等离子引擎与多人飞船

亚光速引擎＋等离子引擎图纸在引擎升级台合成等离子引擎，用于制造九阶多人飞船。图纸由巴纳德C1现有月球式地牢Boss提供。

等离子引擎具有明显的空核心位置，正常支持九阶前往开普勒。九阶船体、控制面板与动力的全部必需原料在开普勒之前取得。总装复用七阶火箭合成台。

### 总装与回收衔接

七阶火箭合成台继续用于九阶组装：鼻锥×1、箭身×2、推进器×1、助推器×2、尾翼×2、控制面板×1、等离子引擎×1→九阶多人飞船×1。等离子引擎占中间引擎槽，控制面板占右上功能槽。

九阶采用六座布局：鼻锥驾驶舱两席，两段箭身各两席。七阶鼻锥继承一席，升级鼻锥增加一席，两段箭身各投入两个座椅，新增五席。多人实体提供六个实际乘坐位置。

各部件承担以下功能：鼻锥负责前端防护，箭身负责舱段与承力结构，推进器负责主喷口结构，助推器与尾翼沿用七阶结构升级；紫晶复合组件集中供给箭身、推进器与控制面板，等离子引擎作为独立动力模块装入中央槽。

单船升级以一套七阶配件及一台亚光速引擎为基础，追加投入分两层核算：

| 备料层级 | 数量 |
| --- | --- |
| 配件与控制面板的直接输入 | 紫晶板×37、紫晶复合组件×8、紫晶晶圆×4、锌基连接组件×4、隔热衬层×2、深空航电组件×2、GS信息面板×1、GC座椅×5 |
| 展开紫晶复合组件后的加工总量 | 紫晶板×45、紫晶晶圆×8、锌基连接组件×12；隔热衬层、航电、信息面板与五个座椅同上 |
| 紫晶加工的基础原料 | 紫木×186、树脂×99、红石×3、现代晶圆×3；其余太阳系组件按既有配方备料 |
| 新增座椅原料 | 压缩钢×25、压缩铁×5 |
| 动力升级 | 亚光速引擎×1＋等离子图纸×1→等离子引擎×1 |

两种备料层级择一使用。45块板与8枚晶圆含复合组件的加工消耗；晶圆制作三批得到9枚，余1枚，全部紫晶加工需要93锭。GS信息面板、深空航电与连接组件各自消耗的现代晶圆等太阳系原料另计。

星际组装台有十个输入槽和一个输出槽，结构推进器与独立动力模块分开投入，右上功能槽放七阶图纸或控制面板。GS七阶替代总装入口继续使用原16格库存的中央索引14及三货舱槽。九／十阶实体共用六座与回收逻辑，保留燃料和已有货箱规格。

拆解台将七／九／十阶火箭按完整总装用量返还结构件、图纸或控制面板及已装引擎，已有货箱另行返还。七阶配件可用于九阶制造，九阶拆回的船体与控制面板可配黑洞引擎重装为十阶。该台与九／十阶火箭同期加入，界面使用 GS 火箭装配机：火箭放在成品槽，部件出现在零件槽。对应输出格为空或可叠上相同部件时会拆。六阶火箭不在其配方中。

九阶、十阶放在世界上的船体，以及物品栏和手持，使用 EP 已注册的 `rocket_t9` 与 `rocket_t10_new` 模型。十阶尾焰使用 GC 的发射火焰，喷口位置与 EP 十阶相同。

## 九阶开普勒探索与十阶制造

### 最终能源核心与黑洞引擎

开普勒的蓝、红、紫、黄、绿五种钻石与铂制品共同制作最终能源核心。五色钻石各×1与铂板×4，在GS装配机制造核心×1。

黑洞引擎由引擎升级台完成最终装配，核心原料在终章之前取得。装配完成时制作台炸开，仅移除台体，完整释放库存与引擎成品，周围方块与玩家不受损。

### 十阶飞船

七、九、十阶共用同一台火箭合成台。拆解九阶后，全部九阶配件与控制面板再次投入原总装槽位，中央由等离子引擎改为黑洞引擎，组装出代码等级T10的六座飞船。十阶总装仅动力输入不同，沿用九阶配件；核心消耗由黑洞引擎配方落实，航行时校验十阶飞船身份。

十阶尾焰使用与 EP 十阶相同的 GC 发射火焰和四喷口位置，倒计时和升空都会绘制。颜色先留在 Recipe Studio，不另做一套粒子。
