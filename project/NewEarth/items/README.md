# 物品与制造

本线负责太阳系整合、七阶制造、系外工具、九阶多人飞船与十阶能源升级。

## 配方讨论工程

[制造台界面参考](ref-component-assembler-gui.png)用于核对物品栏、输出、电量与状态的布局。

[Recipe Studio 工程](recipe-studio.json)包含GS原版四、五、六阶的配件、材料加工与总装参考，以及GC、GS、EP制造材料库。原配方取自`CraftingRecipesOverworld.java`的普通火箭制造分支。

七阶草案位于原版参考区右侧，包含材料加工、五类配件及主体总装。九阶材料与配件区位于画布右侧，按游戏配方展示紫晶加工、七阶配件升级、控制面板及单船备料；总装图包含中央等离子引擎和右上控制面板。

将`recipe-studio`工具仓库放在Minecraft仓库的同级目录，从Minecraft仓库根目录启动：

```sh
python ../recipe-studio/server.py --state project/NewEarth/items/recipe-studio.json
```

打开`http://127.0.0.1:8766/`，调整物品、数量、配方和模板。工程自动保存至上述文件；文件采用服务端的`revision`与`project`封装。需要浏览器“打开工程”格式时，使用页面“保存工程”导出。

## 当前功能

- 整合太阳系主星和卫星归属，按阶段检查航行准入。
- GS六阶仅支持离子引擎改装，七阶仅支持亚光速引擎改装；回收火箭保留引擎状态。
- 星图目录与详情面板支持独立滚动。
- 裁剪旧EP火箭、重复装备、防护服与温控、彩色普通氧气罐及两种炸弹，保留矿物、加工机器和容量升级氧气罐。
- GS普通／轻型宇航服承接EP气压与辐射防护，GC／GS温控承接EP天体温度环境。
- EP镁／镍统一到GS锭、板与材料块，铅统一到GC金星铅锭；冶炼、加工及配方使用统一材料，重复材料与材料块退出获取、矿词、创造栏和JEI列表，不保留旧材料转换。
- 地牢按星球提供四至七阶制造、两种制造台及亚光速引擎图纸；四／五／六阶图纸在GS装配机中转换为对应许可。Io离子引擎概率为5%。
- 星际装配机（材料制造台）加工四类中间件，GS装配机制造七阶配件；星际组装台或GS火箭装配机完成七阶总装，中央槽消耗亚光速引擎，成品保留动力状态。
- 紫木烧制紫晶碎片，材料制造台加工紫晶锭与复合组件，GC压缩机加工紫晶板，电路制造机将EP钻石晶圆改为紫晶晶圆。
- GS装配机提供九阶五类配件、信息面板与控制面板配方；巴纳德C1实际月球式地牢Boss提供等离子图纸，引擎升级台提供亚光速＋等离子图纸的升级配方。
- 常规系外目的地最低T7，开普勒最低T9；Eris六阶必须实际安装离子引擎，七阶及以上按有效飞船放行，星图与服务端传送使用同一判定。
- 星际组装台共用七／九／十阶配件布局：八个结构件、中央动力模块、右上图纸／控制面板，输出对应火箭。七阶使用亚光速模块与七阶图纸，九／十阶使用控制面板及等离子／黑洞引擎。拆解台返还对应结构件、功能件、已装引擎和货箱。
- 星际组装台直接使用GC原版NASA工作台的方块与物品模型，沿用GS总装界面纹理、槽框及背包布局，底行保留结构推进器，中央独立放动力模块。每个输入槽放一件，快捷移入按部件分槽，JEI与容器槽位对应；总装无需电力，沿用GS普通模式的加工时长与进度条，默认720 tick（36秒），随GS火箭装配速度系数调整；完成后才消耗输入并输出成品，进度随存档保存。
- 星际组装台和拆解台均在GS装配机以复合板×4、深空航电×1、连接组件×2、压缩钢×2制作。
- 最终能源核心在GS装配机以蓝、红、紫、黄、绿钻石各×1及铂板×4制造；引擎升级台以等离子引擎×1＋核心×1制造黑洞引擎。完成时制作台本体散开，库存与成品掉落，周围方块及玩家不受爆炸伤害。
- 十阶离开大气层后固定前往终章；同行名单由实际同船乘员建立，飞船与货物由驾驶员回收。终章内起飞使用常规目的地选择返航。
- 材料制造台与引擎升级台仍共用FE加工，每批200 tick、每tick消耗40 FE。JEI已注册加工、组装与拆解配方。两种新工作台破坏时掉落库存。旧27槽制造台库存从输出槽逐批取回。
