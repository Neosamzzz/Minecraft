# 物品与制造

本线负责太阳系整合、七阶制造、系外工具、九阶多人飞船与十阶能源升级。

## 配方讨论工程

[制造台界面参考](ref-component-assembler-gui.png)用于核对物品栏、输出、电量与状态的布局。

[Recipe Studio 工程](recipe-studio.json)包含GS原版四、五、六阶的配件、材料加工与总装参考，以及GC、GS、EP制造材料库。原配方取自`CraftingRecipesOverworld.java`的普通火箭制造分支。

七阶制造区位于原版参考区右侧，包含材料加工、五类配件及主体总装。九阶材料与配件区位于画布右侧，按游戏配方展示紫晶加工、七阶配件升级、控制面板及单船备料；总装图包含中央等离子引擎和右上控制面板。工程还包含十阶总装、三段引擎升级、最终能源核心及四种制造设备的配方；亚光速引擎只作制造材料。

将`recipe-studio`工具仓库放在Minecraft仓库的同级目录，从Minecraft仓库根目录启动：

```sh
python ../recipe-studio/server.py --state project/NewEarth/items/recipe-studio.json
```

打开`http://127.0.0.1:8766/`，调整物品、数量、配方和模板。工程自动保存至上述文件；文件采用服务端的`revision`与`project`封装。需要浏览器“打开工程”格式时，使用页面“保存工程”导出。EP 引擎图标和模型是否复用，先在该工程里比较素材，不进入当前制造实现。

## 抽屉取料

手动整组取料时，如果点击的格子有多个物品且本次会取完，就留下 1 个。只剩 1 个时，再取一次即可拿走。压缩抽屉按点击格对应的物品数量判断，库存仍按原比例换算。

创造模式的「新地球」标签和 JEI 中的 NewEarth 物品均按设备、管道、材料及火箭阶数排列。JEI 搜索 `@NewEarth` 可只看本模组；设备和管道的用法见对应物品的 JEI 信息页。

制造设备的主体可以直接贴在抽屉控制器或控制器传动方块上，也可以用传输管道连到它们。JEI“＋”从玩家背包和所连的抽屉网络取普通原料，优先使用背包。Trim 用于连接抽屉网络，取料入口为抽屉控制器或控制器传动方块。同一设备连接不同抽屉网络时拒绝取料。

传输管道和气密传输管道可六面混接，无需调整朝向。细管接到设备时显示接头，接另一节管道时直接连通。气密传输管道是可用于 GC 密封墙的完整方块，可以直接贴设备。普通管道用上下各一块致密铁板夹任意颜色羊毛，产出 6 根。气密管道用左右各一块锡饰墙砖夹一根普通管道，产出 1 块。

把管道从机器接到一个抽屉网络，即可将受支持的 GC、GS、EP、NewEarth 机器和原版熔炉的物品成品自动入库。管道贴在机器任意一面都能从其开放的成品槽取货。原料、燃料和电池留在机器中。出口只接抽屉控制器或控制器传动方块，多个入口连到同一个控制器时视为同一个仓库。无可用仓库、连接不同仓库或线路所在区块未完整加载时暂停。抽屉拒收时成品留在机器。

普通点击填至一份配方所需数量，Shift 点击按背包、抽屉可用余量及输入槽容量尽量填入多份完整配方，不记忆配方或持续补料。每个抽屉储物格保留最后 1 个物品，背包材料可用完；压缩抽屉的不同形态共享余量，保留当前有库存的最大压缩形态 1 个，例如有铁块时至少留下 1 铁块等价库存，只有铁锭时至少留下 1 铁锭。

JEI“＋”提前检查背包与抽屉可用原料，检查期间或材料不足时按钮不可点击。鼠标移到因缺料而禁用的按钮上时，对应材料格会以红色闪烁；配方页面打开期间约每半秒刷新一次，补足材料后清除提示。原料格里不符合新配方的物品先退回背包；背包放不下时也禁用按钮。检查只读取库存，点击后服务端再核对一次；多人同时取料导致库存变化时可能拒绝本次填入，并保持原有库存。无抽屉连接时保留已有 JEI 填入方式，没有原处理器的已适配设备可使用背包取料。

关闭原版工作台时，无论有没有拿走成品，更新后通过 JEI 从抽屉填入、尚留在合成格中的原料都会自动退回原抽屉。合成消耗或手动拿走的部分不再归还；背包原料和后来手动加入的材料正常回背包。原抽屉已拆除、封装、权限改变或容量不足时，无法归还的部分回背包，背包放不下则掉落。机器和持久化工作台继续保留其原有库存规则。

| 设备 | 接入范围 |
| --- | --- |
| 原版工作台、GC 磁力工作台 | 九宫格普通材料 |
| GC 普通／电动压缩机、GC／GS 电路制造机 | 配方输入，排除燃料、电池和输出 |
| NASA 工作台 | GC 一／二／三阶、货运火箭、月球车、采矿机；GS 鼻锥、箭身、推进器、助推器、尾翼、氧气罐及二阶页面的普通原料 |
| GS 元件装配机、火箭组装机、通用回收机 | 普通制造原料，排除动力、图纸、电池、升级及容器槽 |
| NewEarth 星际装配机、星际组装台 | 普通原料及结构件，排除引擎、图纸和控制面板 |

图纸、控制面板、引擎等特殊输入继续手动放置，已有特殊输入保持原样。机器原有加工时间、耗电、配方和出货方式不变。抽屉访问沿用控制器范围和网络连通规则，尊重私有抽屉权限及封装状态，需开启控制器物品输入输出。

## GC 太空采矿机

基础飞行速度是 GC 原版的两倍。钻进时的基础移动速度是巡航的 2.5 倍，每次检查最多开采 12 格，发现新岩面后下一次检查即可破岩。每到一个新采掘点，采矿机会在原有巷道之外，向左、右各偏 8 格各加一条平行巷道。高度允许时，也会在正上方、正下方各偏 8 格各加一条。新增巷道在小行星带长 12 格，在其他维度长 24 格。返航、复工和已保存的作业队列沿用 GC 行为。

手持样品潜行右键基站即可加入或移出丢弃清单，空手潜行右键可查看。清单最多记录 12 种样品，按物品、子类型和标签匹配。基站默认保留全部货物，只有回站卸货时会销毁命中的物品，已经入库的物品照常保留。若库存满，待保留货物留在机内。绑定采矿机后由其拥有者或管理员修改清单。

基站界面可显示电量不足、返航受阻、基站损坏或绑定冲突等故障原因。
