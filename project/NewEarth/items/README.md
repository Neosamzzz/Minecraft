# 物品与制造

本线负责太阳系整合、七阶制造、系外工具、九阶多人飞船与十阶能源升级。

## 配方讨论工程

[Recipe Studio 工程](recipe-studio.json)包含GS原版四、五、六阶的配件、材料加工与总装参考，以及GC、GS、EP制造材料库。原配方取自`CraftingRecipesOverworld.java`的普通火箭制造分支。

七阶草案位于原版参考区右侧，包含材料制造台、钨基复合板、隔热衬层、航电与连接组件、五类配件和主体总装，总装包含推进器部件。物品贴图使用现有素材占位。

将`recipe-studio`工具仓库放在Minecraft仓库的同级目录，从Minecraft仓库根目录启动：

```sh
python ../recipe-studio/server.py --state project/NewEarth/items/recipe-studio.json
```

打开`http://127.0.0.1:8766/`，调整物品、数量、配方和模板。工程自动保存至上述文件；文件采用服务端的`revision`与`project`封装。需要浏览器“打开工程”格式时，使用页面“保存工程”导出。

## 当前功能

- 整合太阳系主星和卫星归属，按阶段检查航行准入。
- GS六阶仅支持离子引擎改装，七阶仅支持亚光速引擎改装；回收火箭保留引擎状态。
- 星图目录与详情面板支持独立滚动。
- 裁剪旧EP火箭、重复装备、防护服与温控、彩色普通氧气罐及两种炸弹，保留矿物、加工机器和容量升级氧气罐。
- GS普通／轻型宇航服承接EP气压与辐射防护，GC／GS温控承接EP天体温度环境。
- EP镁／镍统一到GS锭、板与材料块，铅统一到GC金星铅锭；冶炼、加工及配方使用统一材料，重复材料与材料块退出获取、矿词、创造栏和JEI列表，不保留旧材料转换。
- 地牢按星球提供四至七阶制造、两种制造台及亚光速引擎图纸；四／五／六阶图纸在GS装配机中转换为对应许可。Io离子引擎概率为5%。
- 材料制造台加工四类中间件，GS装配机制造七阶配件，GS火箭装配机完成主体总装；七阶参照六阶在改装台安装亚光速引擎。
- 常规系外目的地最低T7，开普勒当前仍为T10；九／十阶飞船和核心待接入。
