# 终章新维度

Git 分支：[codex/newearth-dimension](https://github.com/Neosamzzz/Minecraft/tree/codex/newearth-dimension)。核对日期：2026-11-02。

新维度与地形生成作为独立工程推进，火箭和相关物品由[物品线](../items/README.md)维护。整体关系见[支线总览](../README.md)。当前仅记录方向，维度尚未实现。

## 体验方向

- 新增独立的拟地球行星，与现有 GS 系外行星和 EP 开普勒分开。
- 近处有熟悉的花草、河岸与地表细节，远处有更宏伟的森林、山脉和大陆，重视近景熟悉、远景辽阔的感受。
- 呼应大部分陆地被海洋吞没的地球开篇。假设不知道最终目的地存在，不提前承担“寻找新地球”的使命(实际还是知道)。
- 抵达时先呈现景色和意外发现，之后由玩家选择探索、建设或定居。
- 保留现有生态星球的森林、海洋和价值，不将它们改写为寻找家园失败的荒地。

“巨型拟地球”描述地貌尺度与景观方向，不据此直接规定球体尺寸、地图边界、具体树种、呼吸条件或生成算法。

## 内容边界

景观优先复用原版、GC、GS、EP 已有的方块、生态和素材，不为终章配套扩展新的矿物、装备或通用工业体系。新维度仍需独立研究生成与呈现，但不承担新火箭物品和制造台的开发。

维度线可独立研究与验证地形和世界行为，不以七八阶火箭已经完成为起点。维度 ID、星图位置、环境参数与生成方式尚未确定。

## 发现与 FTB 呈现

发现前不展示终章名称、封面或目的地信息；章节、节点、通知和星图等需要共同考虑。具体揭示方式后续核实，不将某个隐藏选项当成已经实现的保证。

「似曾相识」与 H01 抵达占位由 `docs/ftb-quest-manuscript.md` 维护，最终在维度接入后对接。基础 FTB 内容独立推进，不等待新维度完成。

## 与火箭线的接口

终章最低准入等级确定为 T8，使用八阶火箭抵达，七阶不能进入。后续共同确定维度标识、星图归属、正常到达与返回，以及发现时机；准入等级需要在天体注册、星图与实际通行检查中保持一致。

此规则不要求两线等待彼此才能开发：维度线仍可独立研究地形，物品线独立验证火箭，最后对接八阶前往终章的完整流程。当前尚未实现新维度或 T8 准入检查。

本页记录方向，不预排具体开发任务或锁定地形算法。
