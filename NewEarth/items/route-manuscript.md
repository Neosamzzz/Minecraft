## 整合原则

- 做深度魔改整合包，以 GC／GS 的主要制造、加工、装备与防护体系为基础，按需要调整模组、配置和配方。
- 定稿 config 作为固定玩法的一部分随版本交付，不支持替换配置切换模组组合；后续按正式配置逐项维护，禁止原版、旧备份或实例配置整份覆盖，执行[根 README 的固定配置交付约定](../../README.md#固定配置交付约定)。
- 根据保留星球的实际矿物与特色产出设计新配方；不沿用 EP 原七阶板材链，也不先规定部件再为其补造资源。七阶前可达的 GS 内容参与七阶制造，具体目的地范围和资源分工待细化，系外材料不能作为首次七阶前置。
- 保留的材料必须接入实际加工、制造或升级，尤其保证后段星球特色材料有用途；可分配到七阶、九阶与十阶，避免删除旧装备后留下用途空缺。机器只要仍有加工、供电、供氧、精炼、加注、净水等实际作用就保留，功能相近不作为裁剪理由；具体加工改造另行设计。
- EP 提供选用的地表、矿物、Boss、地牢、结构及适合复用的机器和表现素材。大部分不采用的 EP 工具、武器、护甲与防护装备退出生存流程：移除配方和其他获取入口，并隐藏 JEI 条目；不是只改配方名称。具体裁剪名单待逐项确认。
- 原 EP 各阶火箭、专用部件与板材、旧图纸及制造路线先整体退出，含原七阶和电力十阶；按新火箭设计选择性复用，不预先锁定旧部件。模型、贴图等作为候选素材；矿物、通用材料和有用机器分别保留。非合成获取入口的最终审查由其他实现方负责。
- 主星、卫星归属一起整理，但不要求同一体系全部使用同一模组：允许 GS 卫星挂到 EP 主星。不同实现的矿物、环境和奖励不能混写。
- 以 GS 装备能力适配环境。土星体系处于五阶阶段，海王星体系、冥王星和 Eris 处于六阶阶段；环境具体参数和其余新启用天体门槛待适配。防护材料必须在出发前可得。

## 地牢奖励与引擎迭代

| 地点 | 新关键奖励 | 边界 |
| --- | --- | --- |
| EP 水星 | GS 四阶火箭图纸 | 唯一获取来源，替换原 EP 四阶图纸 |
| EP 木星 | GS 五阶火箭图纸 | 唯一获取来源，替换原 EP 五阶图纸 |
| EP 土星 | GS 六阶火箭图纸 | 唯一获取来源，替换原 EP 六阶图纸 |
| EP 天王星 | 特殊道具图纸 | 具体道具待定，替换原 EP 七阶图纸 |
| EP 海王星 | 特殊制造台图纸 | 替换原 EP 八阶图纸；先造台，之后重复加工 |
| EP 冥王星 | 七阶火箭图纸 | 替换原 EP 九阶图纸 |
| EP Eris | 亚光速引擎图纸 | 替换原 EP 十阶图纸；电力十阶图纸等旧奖励也需审查 |
| GS Io | 离子引擎 | 引擎奖励仅保留离子，移除直接取得亚光速引擎的入口 |

引擎采用同一条路线迭代升级，旧代引擎作为下一代的投入。路线确定为离子→亚光速→等离子→黑洞：六阶安装离子前往 Eris，取得亚光速图纸；七阶阶段使用亚光速支持常规系外航行；等离子引擎用于制造九阶多人飞船、前往开普勒；黑洞引擎用于制造十阶飞船、前往终章。各代配方和数量待定，九阶不能依赖开普勒原料；黑洞引擎以等离子引擎为基础制作。等离子引擎完成时保留一个可被玩家注意到的空核心位置；这个位置用于容纳开普勒五色钻石与铂制品制作的最终能源核心，取得核心后补全这一处，承接黑洞引擎与十阶升级。空位不妨碍等离子阶段的正常功能和九阶前往开普勒；具体装配交互、配方与核心消耗或保留方式待定。原 GS 改装台支持安装、拆卸并返还已支持的引擎；新引擎及六阶离子安装要适配。不能把物品存在或 WIP 引擎类型当作已有完整功能。

黑洞引擎完成演出：在制作台装上引擎并完成最终装配后，制作台炸开，原处留下完成的黑洞引擎。炸开的制作台本体属于这次制作演出的结果，不波及周围方块，也不造成任何伤害；不得让爆炸摧毁或丢失引擎成品。具体制作台选型、装配触发步骤、声光效果及成品呈现方式待实现时确定。该演出尚未实现。

## 接下来敲定什么

1. 按指南的实际资源底表，分清独立材料与重复材料；镁方向上统一为 GS，镍、铀和其他材料分别核对。不因名字接近把 EP 水晶与 GS 未知晶体、EP 火山锭与 GS 火山石视为同物。
2. 从保留的矿物、冰晶体和其他产出出发，设计加工组合，再确定七阶部件、制造台和引擎升级配方；不沿旧 EP 七阶链补依赖，不要求给每种原料硬塞七阶用途。
3. 检查原料在当前阶段可达、能取得、能加工，并实际用于后续制造；环境与防护同步形成闭环。
4. 配方与规则明确后再实施：星图与注册、环境、奖励、旧配方裁剪、制造和航行；分段进行生存探索、加工和往返验证。

## 表现与后期候选

- EP 七阶体量偏小；九／十阶模型作为后续载具素材候选，均可改造或重做，不强制沿用 EP 美术。
- 尾焰参考 EP 电力十阶效果，并做适当调整；普通／电力十阶现有粒子代码相同，不因此确定动力系统。
- GS 信息面板的界面风格拟复用于十阶的控制面板制造路线；不是已决定制作目的地选择或启航控制 UI。具体界面在制造中的用途未定。
- 后期统一为九阶基础多人飞船、十阶最终升级，替代旧八阶口径；十阶依靠黑洞引擎并满足最终能源核心条件前往终章，具体制造方式待定。
