# 后期航天与系外探索物品线

维护分支：[main](https://github.com/Neosamzzz/Minecraft/tree/main)。更新日期：2026-11-02。

本线负责七阶火箭、八阶多人宇宙飞船、装配与能源升级，以及系外星球相关的物品和专用工具。终章新维度由[维度线](../dimension/README.md)独立推进，共同方向见[NewEarth 总览](../README.md)。NewEarth 0.1.0 已实现七阶制造与常规系外等级衔接；新增八阶载具、工具、工作台和核心尚未实现，七阶正常航行仍待实测。

> [!IMPORTANT]
> **交接与设计前先读 [planet-gameplay-guide.md：星球玩法详解](https://github.com/Neosamzzz/Minecraft/blob/main/docs/research/planet-gameplay-guide.md)。**
> 各星球的现有资源、环境、制造关系及待验证事项在这份 guide 中查阅，它是本线的重要依据，不只是 FTB 文案参考。共用资料与本线方向统一在 `main` 维护，现有玩法依据以该指南为准。

## 整体方向

**太阳系发展 → 七阶火箭 → 常规系外探索 → 八阶多人宇宙飞船 → 开普勒资源 → 最终能源核心 → 终章行星。**

七阶延续已有火箭体系；八阶在载具形态、独立装配设备与多人同行体验上形成新的发展阶段。各个系外目的地应有自身的资源与工具价值，让探索所得接入后续制造和升级。

本页维护整体目标、实现进度与选型；配方和行为以源码为准。既有方向可随依赖调查与实际验证调整，不把早期文档当作不能修改的工程限制。

## 实现状态与构建

源码统一归属 `NewEarth/src/main/`，交付独立附加模组 `NewEarth`，不替换 GS、EP 原包，也不将新玩法塞入遥感补丁 GSLC。构建配置为 `NewEarth/build.gradle`，复用已有 GalaxySpace Gradle Wrapper、ForgeGradle 4.0.23 和 GC 编译依赖，不新增固定二进制材料。

根目录执行，先配置 JDK 8：

```powershell
py -3 tools/build.py --target newearth --offline
```

首次缺少缓存时去掉 `--offline`。产物为 `build/libs/NewEarth-0.1.0.jar`；客户端与服务端都需要同版本 NewEarth，以及已有 GC、GS 2.2.0、EP 0.8.0 和它们的依赖。后续版本以 `NewEarth/gradle.properties` 为准。当前源码编译使用共用 GC 4.0.2.283 开发依赖，目标运行基线仍为 GC 4.0.6；隔离检查不证明这两个版本的完整运行兼容。

### 0.1.0：七阶衔接

- GS **装配机**用纸、六阶许可和四份六阶强化板制作 EP 七阶图纸；在 GC NASA 工作台解锁既有七阶页面后，用 GS 六阶头锥、引擎、两枚助推器、四片稳定翼与十份六阶强化板制造七阶火箭。三处箱子槽的八种摆放均支持，对应 0～3 货舱。不消耗已加油或带物资的成品火箭。
- 输入均来自现有太阳系制造链，不要求 EP T4～T6 专属材料、地牢掉落的七阶图纸或系外资源。原 EP 材料配方保留；新增配方接入同一个 NASA 页面，槽位由配方输入动态接受 GS 材料。GS 火箭装配机仍负责原 T4～T6，不把内部库存容量当作界面开放槽位。
- 已注册的比邻星 b、巴纳德 C、巴纳德 C1、鲸鱼座 τ f 改为 T7；禁用的天体保持禁用，太阳系等级不改。GS/AsmodeusCore Provider 根据同一天体的等级判断通行，星图与服务端共用该值；实际星图操作、跨系选择与航行仍需运行验收。
- EP 七阶仍依赖其 `URANUS` 开关完成原物品注册。缺少必要物品时启动明确报错，不自动启用或关闭星球。开普勒的 `KEPLER22B && KEPLER_SOLAR_SYSTEMS` 及其他 EP 生成器依赖仍需保留和逐项检查；这版没有完成 EP 裁剪。
- 开普勒暂保留原 T10 门槛。待基础八阶可用时再接入 T8，不先用原 EP 八阶替代自制飞船阶段。

移除两端 NewEarth 可撤销这版启动时的配方与等级调整；沿用 EP 的火箭物品不会因移除附加模组而换 ID。移除前让玩家及载具回到安全基地，避免将已有系外行程留在变化后的门槛之外。本轮只生成开发包，未部署到正式客户端、服务器或存档。

构建自动执行 `progressionCheck`：使用真实 MC 库存、现有 GS 装配机匹配器、GC NASA 配方与测试注册物品，验证图纸制造、八种箱子摆放/四种货舱、许可与材料匹配、缺失注册时不作部分修改、系外等级与太阳系/开普勒边界。51 项通过；共享构建入口的 21 项 Python 检查通过。隔离测试不启动完整 Forge，也不验证机器供电、材料生存获取、实际飞行和返航。检查输出为 `build/checks/newearth/progression/`。

## 整体推进与制造依赖

| 顺序 | 工作 | 依赖与完成条件 |
| --- | --- | --- |
| 1 | 七阶与系外准入 | 0.1.0 已实现代码与构建；下一项是目标运行环境启动、GS 图纸制造与 NASA 页面实际组装、T6 拒绝/T7 通行和一次正常往返 |
| 2 | 系外采集、处理与工具 | 与八阶选材一起推进；先补取得缺口，再接有效用途，不等飞船全部完成后硬填材料 |
| 3 | 独立装配台与基础八阶 | 材料来自太阳系及常规系外；独立装配设备、多人飞船与正常往返均可用后，再开放开普勒 T8 |
| 4 | 核心制造与安装 | 五色钻石全部加铂制品；制造、安装、拆卸与存档状态由物品/载具代码承担 |
| 5 | 终章航行接口 | 对接维度线的实际目的地；服务端检查八阶载具和有效已安装核心，同船乘员共同到达与返回 |

选材依次检查“此前可达 → 能取得 → 能加工 → 进入有效用途”。七阶首次制造不使用系外材料；基础八阶和装配台不使用开普勒材料；最终核心不使用终章材料。常规系外保留并行分支，不强制逐星排队完成。

### EP 太阳系星球保留（2026-11-02 确认）

保留并适配 **EP 海王星与 Eris（阋神星）两颗可登陆星球**，不是仅复用对应火箭模型，也不因此恢复 EP 整套太阳系。优先复用两颗星球已有地形、资源、Boss 与地牢，作为太阳系后期探索内容。

两颗星球如何参与七阶材料与解锁、各自准入等级、奖励和防护要求仍待细化；原 EP 门槛分别为 T7、T9，不代表已改为六阶。Eris Provider 的硬编码通行等级、旧板材链及七阶物品与天王星开关的绑定需一起适配，不能只改星图显示。0.1.0 的直接合成图纸与 GS 材料路线是当前实现，后续应随确定的探索路线审查，避免绕过新增内容。本次只确认保留方向，尚未修改实例配置、配方或准入。

当前资源接入重点：比邻星先验证已有地表/木材回收与补给价值，尚不虚构独占稀有矿；巴纳德 C 先核实树汁采集，再评估密封与维护用途；C1 优先复用缟玛瑙已有晶圆加工；鲸鱼座 τ f 先解决生存采样，再确定水下采集工具和样本用途。以上是下一轮实现切入点，尚未新增配方或专用工具，不作为八阶已确定的强制材料表。资源事实、来源和现有加工仍查 guide，不在此复制百科。

## 各星球的资源与工具

- 每个可登陆的系外目的地都应有可用的特色材料，并有相应的专用工具或采集、处理能力支撑当地玩法。不能只有抵达记录，没有可继续利用的收获。
- 专用工具服务于星球差异与实际需要；优先复用、适配已有工具，必要时补充专用物品，不预设每颗星球必须新做一整套工具或装备。
- 资源与既有玩法先查 guide，再结合源码、配置和游戏核实。这里不另列资源清单，也不预先规定某种材料必须制作哪个部件。
- 每颗星球的特色内容最终需落实实际来源、取得方式和有效用途；这些关系不得形成制造或航行的前置循环。现有材料缺少用途或无法正常取得时，需要补齐，而不是把设计写成已有能力。
- 保留并行探索与分工空间。“每颗星球有实际价值”不等于预先规定所有目的地都必须按同一顺序完成。

## 载具与能源主线

| 内容 | 已确定方向 |
| --- | --- |
| 太阳系与七阶 | 保留现有 GC / GS T1～T6 发展；复用 EP 七阶火箭，首次制造条件在此前可达的太阳系阶段取得 |
| 八阶飞船 | 全新宇宙飞船，使用独立飞船装配台，支持多人乘坐；基础动力足以前往开普勒 |
| 最终能源核心 | 在基础八阶造好后，前往开普勒收集五种彩色钻石与铂制品，制作并安装核心，获得终章航行资格 |

最终核心确定要求蓝、红、紫、黄、绿五种钻石全部参与，再加铂制品；具体数量、铂制品形式和配方布局待定。基础飞船、装配台不能依赖开普勒阶段才能取得的材料，核心也不能依赖终章资源；升级后仍是八阶，不新增九阶载具。

多人乘坐是基础要求，设计需覆盖登船、驾驶、同船乘员共同到达与返航，以及掉线、上下船等情况。座位数、船内自由走动、燃料与电力方案仍待定。

## 航行与维度边界

| 目的地 | 目标规则 |
| --- | --- |
| 现有太阳系目的地 | 保留原有 T1～T6 要求 |
| 常规系外行星与卫星 | 最低 T7 |
| 开普勒 | 最低 T8，基础八阶可前往 |
| 终章新行星 | T8 且已安装有效最终能源核心 |

资格按实际飞船和核心状态判断，同船乘员随船航行，不要求每人各造一艘船或各持一枚核心。等级、星图和实际通行检查应一致，不能用团队任务完成代替载具状态。

上述是完整目标。安装 NewEarth 0.1.0 后，四个已注册常规系外目的地调整为 T7，七阶增加 GS 制造路线；未安装的实例保持原 GS 系外 T6。开普勒仍为原 T10，T8 与核心资格检查待后续实现。开发包与隔离检查不代表实际实例已部署或完成航行验收。

本线不承担终章地形与世界生成。可以利用现有目的地独立推进工具、制造、多人航行和核心升级，后续与维度线对接目的地、准入、正常到达和返回。

## 内容与表现边界

原料、方块、生态与基础加工优先复用现有 GC / GS / EP 内容；新增内容围绕系外探索所需的专用工具、飞船、装配和能源升级，不另起庞大的通用工业或装备体系。

飞船装配、启动、核心安装与充能应有可辨认的模型、灯光、粒子和音效反馈。具体美术与特效后续设计；服务端决定实际状态，客户端据此显示。多人乘坐不自动承诺可自由行走的船内世界。

### 模型复用候选（待确认，2026-11-02）

- 七阶考虑复用并改造 EP 七阶模型。现有模型体量偏小，后续评估放大或调整结构的效果，具体尺寸与改造方式未定。
- 新飞船考虑以 EP 九阶、十阶模型作为复用与改造素材。现有外观不够理想，需要评估造型、比例与细节的改进；两套模型如何取舍或使用尚未确定。
- 采用十阶模型的新飞船以 EP 电力十阶尾焰为基础复用，并做小幅改造，不原样照搬；具体调整项目与幅度待定。已核对普通十阶与电力十阶的粒子生成源码相同，均调用 GC 升空/点火粒子；喷口位置、尺度与改造后模型的匹配待实机评估，不因此确定飞船动力系统。尚未修改粒子或渲染。
- 这里的七阶、九阶、十阶指素材来源；九阶、十阶模型用于新飞船，不据此新增对应等级的发展阶段。以上仅记录待确认方向，尚未确定最终模型，也未实施模型或渲染修改。

终章保留独立拟地球行星与意外发现的体验；按主世界正常多人睡眠规则成功过夜后触发共同结尾演出。具体维度与演出方向见[维度线](../dimension/README.md)，本线只对接必要的载具接口。
