# 后期航天与系外探索物品线

维护分支：[main](https://github.com/Neosamzzz/Minecraft/tree/main)。更新日期：2026-11-03。

本线负责七阶火箭、九阶多人宇宙飞船、装配与能源升级，以及系外星球相关的物品和专用工具。终章新维度由[维度线](../dimension/README.md)独立推进，共同方向见[NewEarth 总览](../README.md)。NewEarth 0.2.3 已接入太阳系主星组合、GS 卫星改挂与阶段通行规则，保留 0.1.0 的七阶过渡制造；环境防护、地牢奖励和新制造路线尚未接入。新增九阶载具、工具、工作台和核心尚未实现，正常航行仍待实测。

> [!IMPORTANT]
> **交接与设计前先读 [planet-gameplay-guide.md：星球玩法详解](https://github.com/Neosamzzz/Minecraft/blob/main/docs/research/planet-gameplay-guide.md)。**
> 各星球的现有资源、环境、制造关系及待验证事项在这份 guide 中查阅，它是本线的重要依据，不只是 FTB 文案参考。共用资料与本线方向统一在 `main` 维护，现有玩法依据以该指南为准。

## 整体方向

**太阳系发展 → 七阶火箭 → 常规系外探索 → 九阶多人宇宙飞船 → 开普勒资源 → 黑洞引擎与最终能源核心 → 十阶飞船 → 终章行星。**

七阶延续已有火箭体系；九阶在载具形态、独立装配设备与多人同行体验上形成新的发展阶段。各个系外目的地应有自身的资源与工具价值，让探索所得接入后续制造和升级。

本页维护整体目标、实现进度与选型；配方和行为以源码为准。既有方向可随依赖调查与实际验证调整，不把早期文档当作不能修改的工程限制。

## 实现状态与构建

源码统一归属 `NewEarth/src/main/`，交付独立附加模组 `NewEarth`，不替换 GS、EP 原包，也不将新玩法塞入遥感补丁 GSLC。构建配置为 `NewEarth/build.gradle`，复用已有 GalaxySpace Gradle Wrapper、ForgeGradle 4.0.23 和 GC 编译依赖，不新增固定二进制材料。

根目录执行，先配置 JDK 8：

```powershell
py -3 tools/build.py --target newearth --offline
```

首次缺少缓存时去掉 `--offline`。产物为 `build/libs/NewEarth-0.2.3.jar`；客户端与服务端都需要同版本 NewEarth，以及已有 GC、GS 2.2.0、EP 0.8.0 和它们的依赖。后续版本以 `NewEarth/gradle.properties` 为准。当前源码编译使用共用 GC 4.0.2.283 开发依赖，目标运行基线仍为 GC 4.0.6；隔离检查不证明这两个版本的完整运行兼容。
