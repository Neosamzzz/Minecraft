# 后期航天物品线：七阶火箭与八阶宇宙飞船

Git 分支：[codex/newearth-items](https://github.com/Neosamzzz/Minecraft/tree/codex/newearth-items)。核对日期：2026-11-02。

本开发线维护后期航天载具、必要的专用部件和装配设备，新行星维度由[维度线](../dimension/README.md)独立推进。整体关系见[支线总览](../README.md)。当前是设计基调，尚未实施新载具、工作台或配方。

## 大基调

七阶延续现有火箭体系，负责走出太阳系；随后使用独立飞船装配台，造出支持多人乘坐的八阶宇宙飞船。先驾驶基础八阶前往开普勒取得特殊材料，再制作并安装最终能源核心，获得抵达终章的能力。

优先复用原版、GC、GS、EP 已有材料和加工能力，把新增内容集中在飞船本身及其直接所需的少量部件。制造变化主要通过成品、设备、模型与装配关系呈现，不依赖堆叠材料数量或重新建立通用工业体系。

本页同时给 FTB 内容组提供稳定的预估范围：FTB 可以先写完文案、节点结构和检测目标说明，不等待载具、工作台或终章维度实现。内容编写完成与游戏配置部署、实际运行验收分别记录。

## 发展方向

| 阶段 | 方向 |
| --- | --- |
| GC / GS T1～T6 | 延续已有太阳系发展 |
| 七阶 | 复用 EP 七阶火箭、模型、实体与飞行基础，制造条件接在太阳系末段 |
| 基础八阶 | 全新多人宇宙飞船，使用独立飞船装配台；具备基础动力，可前往开普勒 |
| 最终能源升级 | 开普勒特殊材料 → 制作并安装最终能源核心 → 前往终章；升级后仍为八阶 |

七阶首次制造条件在此前可达的太阳系阶段取得；基础八阶优先利用太阳系与常规系外资源，不能依赖开普勒阶段才能取得的材料。开普勒承担最后的能源升级，不要求所有太阳系或常规系外目的地逐一完成。

目标发展关系：太阳系发展 → 七阶火箭 → 常规系外探索与材料 → 飞船装配台和基础部件 → 多人八阶飞船 → 开普勒特殊材料 → 最终能源核心 → 实际抵达终章。

这是玩法关系，不要求 FTB 把全部目的地、样本或组件锁成强制前置。七阶与八阶也不预设采用消耗前一级完整载具的升级方式。

## 已确定与暂估范围

| 内容 | 基调 | 确定程度 |
| --- | --- | --- |
| 七阶载具 | 复用 EP 七阶模型、实体与飞行基础，调整制造条件和目的地准入 | 已确定方向，配方尚未设计 |
| 八阶载具 | 全新宇宙飞船，支持多人乘坐；基础动力可前往开普勒 | 已确定方向，模型、座位数与具体交互待定 |
| 飞船装配台 | 独立设备、界面和装配配方，不仅是在原 NASA 工作台增加图纸分页 | 已确定方向，外观与结构待定 |
| 飞船专用部件 | 暂估主体、推进、导航、能源、驾驶／维生五类 | 设计候选，可合并、调整或复用现成部件 |
| 最终能源核心 | 使用开普勒特殊材料制造并安装，与飞船基础动力分开 | 已确定升级阶段，选材与配方待定 |
| 终章准入 | 八阶飞船且已安装有效核心，七阶或未升级八阶不能进入 | 已确定设计，尚未实现 |

新增内容暂估为一种装配台、少量基础专用部件、一种完整飞船和最终能源核心；七阶为现有载具复用。五类基础部件与最终核心的拆分尚待细化，核心不能是首次造船的必需输入。这是协作预估，不是逐项新增的固定清单；功能名不作为最终显示名或注册 ID。

多人乘坐已确定，需作为模型与航行流程的基础要求考虑，覆盖登船、座位占用、驾驶权限、同船乘员跨维度到达和返航，以及上下船、掉线等情况。具体座位数和驾驶操作后续确定；多人乘坐不等于已承诺自由走动船舱、船内摆机器或自由太空航行。燃料或电力方案仍待定，不以这些细节阻塞 FTB 编写。

## 现有材料的初步分工

以下为选材候选，不是已加入的配方。已有资源和加工关系的证据见[星球玩法详解](../../docs/research/planet-gameplay-guide.md)。

| 现有材料或部件 | 预估用途 | 取舍 |
| --- | --- | --- |
| GS HDP:2 等现有高级结构材料 | 船体、推进组件的结构基础 | 保留太阳系工业积累的价值，不新增整套高阶板材 |
| EP 铂、压缩铂 | 最终能源核心的候选材料 | 留在开普勒之后的升级阶段，不作为基础飞船或装配台必需输入 |
| EP 彩色钻石 | 最终能源核心或其专用加工件的候选材料 | 不预设五色必须集齐；也不默认它们就是最终选定的关键材料 |
| GS 缟玛瑙 | 导航核心的候选原料 | 可利用巴纳德 C1 探索成果，尚不固定为必需材料 |
| 现有晶圆、导线、航天玻璃、氧气与可取得的储能部件 | 控制、电力、驾驶／维生组件 | 沿用已有加工设备，逐项核对注册、配方及生存可取得性 |

不为每颗系外星球强行分配一种独占原料，不把新矿石或新装备作为补齐配方的默认手段。尤其不能因物品已注册，就引用依赖已关闭 EP 行星的电池、氧气罐或高阶火箭材料作为必需输入。

装配台与基础飞船在开普勒之前即可制造，基础动力必须足以前往开普勒。最终核心原料可由基础八阶取得，不能要求先安装该核心才能采到其唯一原料，也不能依赖终章资源。特殊材料的具体条目和加工方式待核对，暂不另造星球矿石。

## 飞船装配的表达

现有机器继续加工原料和基础部件，独立飞船装配台负责最终专用装配。界面可围绕船体、推进和控制系统呈现整船关系，让玩家清楚当前是在组装宇宙飞船。

工作台的格数、是否多方块、装配时间、耗能和自动化方式留待设计，不作为内容组写作的前提。FTB 只需记录获得工作台、获得完整飞船，不额外开发“真实完成整套装配过程”的自动验收。

## 复用与新增边界

- 优先使用原版、GC、GS、EP 现有的星球材料、采集物、加工产物、机器和基础部件。
- 新增范围集中在八阶宇宙飞船本体、模型、专用部件，以及必要的装配设备、配方和相关表现。
- 新增加工产物应直接服务火箭制造，不另外建立通用材料工业、星球矿石或装备体系。
- 开普勒的铂等可以作为选材依据，不预设每颗系外星球都必须贡献一种独占材料。
- 火箭可以依托 GC / GS 的航天基础，不要求从零重写飞行系统。

## 航行等级方向

| 目的地 | 目标准入规则 |
| --- | --- |
| 太阳系现有目的地 | 保留原有 T1～T6 要求 |
| 常规系外行星、卫星 | 最低 T7 |
| EP 开普勒 | 最低 T8，基础八阶可前往；从原有 T10 门槛适配 |
| 终章新行星 | T8 且已安装有效最终能源核心 |

沿用既有的星球阶数限制，保持天体等级、星图显示与实际通行一致，不额外按 GS / EP 火箭来源划分资格。以上为规划，尚未改写当前实例。

现状仍为 GS 系外注册 T6、EP Kepler T10；当前 EP 七阶组没有正常开放，不能仅凭本方向文档认定已可制造七阶。材料与路线依据见[星球玩法详解](../../docs/research/planet-gameplay-guide.md)，具体配方和准入调整留给本线后续设计。

## 与新维度的关系

终章同时检查 T8 与实际核心安装状态，不能只检查火箭等级或团队任务完成。资格跟随实际飞船，不因一名队友获得核心就让全部未升级飞船通行。同船乘员随具备资格的飞船共同航行，不要求每人各造一艘船或各持一枚核心。

本线可使用现有目的地验证制造、核心升级与多人航行，不等待新维度实现；终章发现、到达返回与正常过夜后的结尾流程由两线对接。这是已确定设计，当前代码和实例尚未实现。

本线不承担终章地形和世界生成。火箭与装配台的最终名称、模型、部件、用量和具体规则后续细化，本页不排开发任务。

## 特效与表现方向

飞船装配、基础引擎启动、安装核心与最终充能应有可辨认的模型、灯光、粒子和音效反馈，突出核心升级前后的差别。现有渲染、粒子与航天基础可作技术参考，新素材和具体演出仍需制作，不把讨论中的效果当作已实现能力。

服务端统一决定载具、核心和航行状态，客户端据此显示效果，保证驾驶员、乘员和附近玩家对同一状态的表现一致。配色、特效强度和模型动画后续细化，不要求 FTB 驱动特效或承担航行判定。

未实现物品的文案、布局和目标说明可以先完成，配置需等真实注册项存在后接入；不得用其他物品或手动勾选冒充实际目标。后续部件、配方和用量变化，优先只调整制造说明及检测映射，不推翻已完成的 FTB 主干。

FTB 内容由 `docs/ftb-quest-manuscript.md` 维护，物品线不复制维护另一份节点文案。角色发现前不提前预告终章；获得八阶飞船不等于已经抵达终章，任务共享完成也不代替火箭准入。
