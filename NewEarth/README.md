# 新地球：多人远航与终章

基调定稿：2026-11-02。

对应 [Project #4「新地球」](https://github.com/users/Neosamzzz/projects/4/views/1) 与 [Issue #8「自建星球」](https://github.com/Neosamzzz/Minecraft/issues/8)。本支线连接后期航天、多人宇宙飞船与独立拟地球行星，为共同旅程安排一次自然的收尾。

**资源与玩法的重要资料入口：[planet-gameplay-guide.md](https://github.com/Neosamzzz/Minecraft/blob/main/docs/research/planet-gameplay-guide.md)。** 各星球现有资源、环境和制造关系在 guide 中查阅；本目录维护新地球设计、实现与对接状态，不复制资源百科。共用资料以 `main` 上的已合并版本为准。

> [!NOTE]
> 本目录维护设计、协作边界与实现入口。NewEarth 0.1.0 已提供七阶制造和常规系外 T7 衔接的开发包，尚未部署或完成正常航行验收；九阶飞船、独立装配台、核心、终章维度与演出待实现。当前实现、构建和验证边界见 [物品线](items/README.md#实现状态与构建)，整体目标不代表已修改当前实例。

## 整体路线

**太阳系发展 → 七阶火箭 → 常规系外探索 → 九阶多人宇宙飞船 → 开普勒特殊材料 → 黑洞引擎与最终能源核心 → 十阶飞船 → 终章行星 → 正常集体过夜后触发结尾演出。**

| 阶段 | 已确定方向 |
| --- | --- |
| 太阳系 T1～T6 | 延续已有 GC / GS 发展；七阶首次制造所需条件在此阶段可取得 |
| 七阶与常规系外 | 复用 EP 七阶火箭，常规系外目的地最低 T7 |
| 九阶制造 | 使用独立飞船装配台，制造支持多人乘坐的九阶宇宙飞船；以等离子引擎参与制造，支持前往开普勒 |
| 开普勒 | 作为九阶造好后的关键目的地，目标最低 T9；收集蓝、红、紫、黄、绿五种钻石和铂，五色全部参与核心制作 |
| 最终升级 | 制作并安装核心，获得前往终章的航行资格；使用黑洞引擎制造／升级十阶飞船，最终能源核心的具体衔接方式待定 |
| 终章 | 独立拟地球行星；准入要求为十阶飞船及已安装、有效的最终能源核心 |
| 收尾 | 在终章按主世界正常多人睡眠规则成功过夜后，触发类似终末之诗的原创结尾演出 |

基础九阶飞船与装配台不能依赖开普勒阶段才能取得的材料，最终核心也不能依赖终章资源，避免制造与航行前置循环。

最终能源核心的材料组合已确定为五种彩色钻石全部加铂制品，不是任选颜色；具体数量、铂制品形式与配方布局待核算。

## 共同方向

- 每个可登陆的系外目的地都应有可利用的特色材料，以及支撑当地玩法的专用工具或采集、处理能力；具体资源查 guide，用途与工具设计留给物品线细化。
- 原料、方块、生态和素材优先复用原版、GC、GS、EP；必要的新增内容围绕系外专用工具、飞船及能源升级，不另建庞大的通用工业或装备体系。
- 终章近景熟悉、远景宏伟，与海洋地球开篇呼应；角色视角不知道终点存在，不提前承担“寻找新地球”的使命。朋友实际知道设定不妨碍按此叙事。
- 保留已有生态星球的森林、海洋和探索价值，不把它们写成寻找家园失败；抵达后先观察和探索，不强制定居。
- 睡眠沿用主世界正常集体过夜语义。结尾由成功过夜触发，不按每名玩家第一次躺床分别播放，也不另设集合观看、参与名单或投票机制。
- 部件选材、数量、座位数、模型、特效、工作台结构和演出文本后续细化，不改变上述路线；重播、跳过等细节另行确定。

## 两条线的对接

后续共同对接维度 ID、星图归属、T9 与核心有效性检查、多人到达和返回、发现时机，以及成功过夜后的结尾触发。终章资格按实际飞船与核心状态判断，不能只检查等级或 FTB 完成状态。

服务端判定航行与过夜等实际状态，客户端负责模型、粒子、音效和演出显示。具体实现归属在两线对接时明确，不要求 FTB 承担这些机制。

## 与 FTB 的关系

[FTB](../docs/README.md) 后续根据实际资源、工具与成品补充轻量任务，不作为两条开发线的前置。任务不逐项覆盖所有部件，也不承担核心安装、航行或睡眠演出判定；文案仍由 `docs/ftb-quest-manuscript.md` 维护。
