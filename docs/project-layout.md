# 目录与构建产物

| 目录 | 内容 |
| --- | --- |
| `project/GSLC/` | GSLC 补丁源码、测试、打包器与固定底包 |
| `project/FTB/` | FTB 源码、任务配置与内容文稿 |
| `project/NewEarth/` | NewEarth 源码、物品与维度设计 |
| `dependencies/` | 上游源码、共用编译依赖及来源登记 |
| `tools/` | 跨项目构建入口与检查 |
| `config/` | 随整合包分发的固定运行配置 |
| `docs/` | 跨项目共用的玩法与资源资料 |
| `build/libs/` | 最终模组包 |
| `build/checks/<模块>/<检查项>/` | 检查输出，默认只保留最近一次结果 |
| `.local/` | 本机环境与依赖配置，不提交 |
| `server/` | 服务端实例与数据，不提交 |

Gradle 中间产物留在对应工程的 `build/`。固定底包不是缓存；自定义检查输出目录不得自动清空。`.local/` 和 `server/` 可能包含不可再生成的数据，不能作为构建缓存清理。
