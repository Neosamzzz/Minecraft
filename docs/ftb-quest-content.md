# FTB 太阳系任务定稿表

本表用于制作、审阅和调整 FTB 任务，列出采用的任务、游戏内文字、完成目标及编排关系。文档供制作时查看和确认；游戏内任务书负责增加游玩目标与乐趣。

候选内容见[预备稿](ftb-quest-manuscript.md)，玩法依据见[物品核对](research/quest-item-notes.md)及[星球玩法详解](research/planet-gameplay-guide.md)。保留原编号便于对照，表格行序不代表强制完成顺序。

## 采用范围与写法

- 六章采用 **44 个独立任务**；原太阳系 60 项中的另外 16 项并入相关说明或不再单独编排，取舍见文末。
- 保留有辨识度的标题。正文有必要再写，主要补充目标用途、整合包特有的变化或可选玩法；不套用“用途／操作／提示”，不添加冒险旁白或基础教学。
- “—”表示不另写正文，只保留标题与目标；不是游戏内占位文字。编排和制作备注仅供作者使用。
- 目标以获得物品、实际抵达和有效击杀为主，不配置奖励。物品数量默认 1，不消耗，不限定制作、交易或采集来源。
- **当前游戏仍运行原六章、60 个目标及旧正文。** 本次只整理内容定稿表，没有改写 SNBT、部署或删除进度；44 项是下一次配置调整采用的内容范围。

## 转配置时核对

- 采用节点继续沿用原任务和条件 ID；本表编号不重排，不复用并入节点的编号。
- “并入说明”不代表合并后台条件，也不意味着提高物品数量或增加前置锁。
- 原 60 项已在实例中使用。后续调整时需单独处理并入项的旧定义与历史进度，不能直接据表删掉团队数据；本次不执行迁移。
- 形状、大小、错位分叉与连线按制作备注落实后，再做游戏显示检查。本表不表示现有配置已采用这些表现。
- F06 之后的系外、七八阶、开普勒、能源核心与 H01“这是...”继续留在预备稿；既定路线与发现后揭示原则不变，不因本次精简提前部署。
