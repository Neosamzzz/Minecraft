# FTB 任务内容稿

更新日期：2026-11-02。关联 [Issue #12：按星球资料组织任务内容](https://github.com/Neosamzzz/Minecraft/issues/12)。

## 使用方式

这是可继续维护并转为任务配置的独立内容稿。标题与说明供玩家阅读；目标与编排备注供配置者使用。玩法依据见[星球玩法详解](research/planet-gameplay-guide.md)，表达原则见[内容方向](ftb-content-direction.md)。部署、实测状态统一记在[资料总览](README.md)。

当前只有[三个节点小样](../quest-config/preview/README.md)已转为配置并加入本机；日志读入不等于完成全部节点验收。下文是作者侧文稿，不能整篇直接放入玩家任务书。物品筛选依据见[任务关键物品核对](research/quest-item-notes.md)。

- 一个节点对应获得一件东西、抵达一个地方或完成一个明确事件，接近原版进度的粒度。
- 所有物品目标默认数量为 1、不消耗物品；“获得”不限定制作或当地采集。不要求玩家逐个制造全部零件。
- 不配置任务奖励。不添加只为阅读而勾选的任务，不要求每名玩家重复完成。
- 正文中的建议不是额外完成条件。拥有氧气罐不表示已充氧，拥有机器不表示机器已经工作。
- 编号供文稿引用，不是部署 ID。章节内按发展方向摆放，表格行序不等于必须逐项完成。
- 后续星球已有静态依据，但飞行与环境仍有待验项；文稿列出内容不表示已验收可达。发布时按实际验证结果启用。
- 新增的载具、工具、补给与基地设备均作为并行支线，不要求全收集。七八阶、Kepler 准入适配与终章保留待接入节点，不提前细化部件配方，不阻塞现有内容。
- 后期按最新路线编写：七阶 → 常规系外探索 → 多人八阶飞船 → 开普勒特殊材料 → 最终能源核心 → 终章。先取得普通八阶飞船，再完成最终升级；结尾演出属于模组流程，不增加 FTB 睡觉任务。
- 后续追加任务沿用已有任务和条件的固定 ID，新内容使用新 ID；不通过删除重建替换旧任务。历史击杀、过去到访不保证自动补记，更新前保留任务配置和团队进度备份。

## 轻量主线与信息揭示

以下是作者侧的整体设定，不直接作为开场剧情全部展示：

- 起点是大部分陆地已被海洋吞没的地球。玩家仍在这里建设、制造和生活；淹没原因、发生年代与文明命运暂不补写。
- 叙事按角色起初不知道最终行星存在来写；一起玩的朋友实际可能知道终章计划。出发来自眼前的好奇和发展需要，不提前发布“寻找新地球”任务，也不把绝对保密作为整个体验成立的条件。
- 途中可以偶尔望回地球，感受到远行的距离；不把每颗星球都写成寻找家园失败，也不将实际有生态的目的地改写为荒地。
- 四级火箭是一次发展转折：GC T1～T3 的基础航天之后，转入 GS 材料加工、部件制造与火箭装配体系。T4～T6 作为这段新发展的重要里程碑；离开太阳系另以“更遥远的地方”记录，不把获得六级火箭当作已跨星系。
- 八阶飞船支持多人乘坐；获得飞船是制造里程碑，最终能源核心是之后的升级目标。制造基础飞船与独立装配台不得依赖只有这一阶段之后才能取得的开普勒特殊材料，避免发展循环。
- 最后的自定义行星是意外发现：近处有熟悉的花草与河岸，远处是尺度更宏伟的森林、山脉与大陆。与开篇的海洋地球形成呼应，先呈现抵达和观察，再留给玩家选择如何探索、是否定居。
- 正式任务书尽量在发现前收起终章名称、封面和目标信息，让抵达时的场景承担表达。触发与揭示方式待维度接入时确定，不为保密承诺新增隐藏机制。

主线主要落在章节开场与少数里程碑，普通节点仍是简短的物品、到达或击杀目标。玩家可以只按玩法推进，不需要阅读成段故事。

章节说明：海洋吞没了大部分陆地，我们在剩下的土地上安了家。海岸之外还是海，抬起头，月亮倒是一直都在。

支线：A12、A15、A16 放在出发准备旁，A13、A14 靠近月球探索。月球车需要对应图纸与制造条件，但不将获得车、取得图纸和每个车轮都拆开。设备持有不代替通电、接管、充氧或实际驾驶验收。

转折表现：C09～C12 在布局上形成独立的制造区域，C12 作为突出显示的里程碑，承接后续 GS 五、六级火箭。文字与布局体现制造体系改变，不增加职业、等级系统或额外解锁规则，也不要求前期每颗星球全部打勾。

C13～C16 为移动、采矿和据点支线。抓钩不设为唯一移动方式；Astro Miner 的持有不保证已经部署或能在所有维度工作。EP 高级电池配方使用 GC 钛材料等，不顺带加入依赖已关闭 EP 行星的终极电池链。

配置备注：升级许可会使用前一级完整火箭，按现有证据先视为会消耗；在 C12 及后续升级节点的详情中补充提示：“升级许可会用到前一级完整火箭，请在安全基地取出货物并办理升级。”不为每张许可另建节点。
