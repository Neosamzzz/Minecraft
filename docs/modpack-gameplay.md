## 物品与材料

### 原料与加工产物

#### 镁、镍与铅

| 材料 | 使用版本 | 获取与加工 |
| --- | --- | --- |
| 镁锭、镁板、镁块 | GS | GS矿源及EP土星镁矿；两枚镁锭压缩为一枚镁板 |
| 镍锭、镍板、镍块 | GS | GS矿源及EP木星镍矿；两枚镍锭压缩为一枚镍板 |

#### 钾盐碎片

钾盐矿经[基础粉碎机](#基础粉碎机)加工获得，用于[基础太阳能蒸发室](#基础太阳能蒸发室)提取[钾](#钾)。

#### 钾

由[基础太阳能蒸发室](#基础太阳能蒸发室)加工钾盐碎片获得。与碘盐一起投入化学注入器，产出碘化钾。

## 设备

### 加工设备

#### 材料制造台

在GS装配机中投入六阶强化板×4、GS现代晶圆×2、GC致密钢板×2和材料制造台图纸×1制造。

右键打开，上两排放入同一配方的原料，下排为成品。每秒加工一批，无需供电；下方漏斗提取成品，其余方向输入原料。配方可在JEI中查询。

| 成品 | 每批原料 | 每批产量 |
| --- | --- | --- |
| 钨基复合板 | 六阶强化板×3、EP钨板×2、EP钯板×1、EP火山锭×1 | 2 |
| 隔热衬层 | EP碳板×2、GS未知晶体×1、冻结氮×4、GS塑料×2 | 2 |
| 深空航电组件 | GS现代晶圆×1、EP白宝石晶圆×1、EP蓝宝石×2、EP锌板×1、EP水晶板×1 | 1 |
| 锌基连接组件 | EP锌板×4、GC铜板×2、GS空白模块×1 | 2 |

#### 引擎升级台

制造材料与材料制造台相同，图纸改用天王星的引擎升级台图纸。输入离子引擎×1与亚光速引擎图纸×1，输出亚光速引擎×1。界面与输入输出规则同材料制造台。

#### 基础粉碎机

用于将钾盐矿加工为[钾盐碎片](#钾盐碎片)。

| 项目 | 内容 |
| --- | --- |
| 制造材料 | 致密汞板 ×4、铁砧 ×2、活塞 ×3 |
| 加工输入 | 钾盐矿 ×1 |
| 加工输出 | 钾盐碎片 ×3 |

#### 基础太阳能蒸发室

用于从[钾盐碎片](#钾盐碎片)中提取[钾](#钾)。

| 项目 | 内容 |

| 加工输出 | 钾 ×1 |

## 载具

### 火箭

#### GS 六阶火箭

采用GS火箭装配机制造，动力模块仅支持[离子引擎](#离子引擎)。

| 六阶目的地 | 版本 |
| --- | --- |
| [海王星](#海王星)及海卫一 | EP |
| [冥王星](#冥王星) | EP |

#### 七阶火箭

GS装配机制造鼻锥、箭身、推进器、助推器和尾翼；GS火箭装配机总装。将鼻锥×1、箭身×2、推进器×1、助推器×2、尾翼×2放入对应槽位，许可槽放冥王星七阶图纸×1。货箱槽可选放一至三个箱子。

总装后的火箭在GS改装台安装亚光速引擎，支持拆卸返还。安装引擎后可点火，使用GS高级发射平台；常规系外目的地包括比邻星b、巴纳德C／C1和鲸鱼座τ f。

七阶火箭暂用GS六阶外观。

## 装备

### 供氧装备

#### 氧气罐

氧气罐储存随身氧气，装入氧气装备栏的罐位使用。供氧系统由氧气面罩、氧气装备和储有氧气的氧气罐组成。

| GC 氧气罐 | 储氧容量 |
| --- | --- |
| 轻型 | 900 |
| 中型 | 1800 |
| 重型 | 2700 |

### 宇航服

GS 普通宇航服与轻型宇航服穿戴于护甲栏。头盔、胸甲、护腿、靴子四件齐全时提供 EP 气压与辐射防护，两种型号可按部位混穿。缺少任一部位会恢复 EP 环境暴露处理。

宇航服防护与供氧、温控分别配备。已有的 EP 辐射累积可使用抗辐射饮料与辐射消除装置处理。

### 温控装备

#### GS 三级温控装备

温控强度为3，包含头部、上身、腿部和足部四件，分别穿戴于温控装备栏的对应位置。手持装备右键可穿入空置的对应温控槽位。EP 木星、土星使用完整三级温控四件套。

#### GS 四级温控装备

温控强度为4，包含头部、上身、腿部和足部四件。穿戴位置与操作同[GS 三级温控装备](#gs-三级温控装备)。EP 天王星、海王星、海卫一、冥王星与阋神星使用完整四级温控四件套。

## 任务系统

### 公共团队

服务器玩家共用一个公共团队，任务进度在团队内共享。

### 任务检测

| 目标类型 | 完成条件 |
| --- | --- |
| 物品 | 持有指定数量；完成检测后保留物品 |
| 探索 | 实际抵达指定目的地 |
| 战斗 | 有效击杀指定目标 |

物品目标接受制作、交易、采集等来源。任务采用无奖励模式。
