## 设备

### 特殊制造台

特殊制造台用于加工七阶火箭材料。[特殊制造台图纸](#特殊制造台图纸)产自海王星地牢。设备支持重复加工。

### 基础粉碎机

基础粉碎机将钾盐矿加工为钾盐碎片。碎片可在[基础太阳能蒸发室](#基础太阳能蒸发室)中继续加工为钾。

| 项目 | 内容 |
| --- | --- |
| 制造材料 | 致密汞板 ×4、铁砧 ×2、活塞 ×3 |
| 加工输入 | 钾盐矿 ×1 |
| 加工输出 | 钾盐碎片 ×3 |

### 基础太阳能蒸发室

基础太阳能蒸发室用于从钾盐碎片中提取钾。钾盐碎片由[基础粉碎机](#基础粉碎机)加工获得。

| 项目 | 内容 |
| --- | --- |
| 制造材料 | GC 基础太阳能板 ×4、致密汞板 ×3、水星石砖 ×2 |
| 加工输入 | 钾盐碎片 ×12 |
| 加工输出 | 钾 ×1 |

## 火箭与引擎

### 六阶火箭

六阶火箭采用 GS 火箭体系。制造图纸产自 EP 土星地牢，可安装[离子引擎](#引擎索引)。

### 七阶火箭

七阶火箭使用亚光速引擎，前往比邻星 b、巴纳德 C、巴纳德 C1和鲸鱼座 τ f 等常规系外目的地。

| 项目 | 内容 |
| --- | --- |
| 制造解锁 | [七阶火箭图纸](#七阶火箭图纸) |
| 材料加工 | [特殊制造台](#特殊制造台) |
| 动力 | 亚光速引擎 |
| 原料范围 | 太阳系阶段可取得的材料 |

### 九阶飞船

九阶飞船支持多人同行，使用等离子引擎，前往[开普勒](#开普勒)。

等离子引擎设有核心安装位。安装位空置时，飞船具备前往开普勒的完整航行能力。

### 十阶飞船

十阶飞船使用黑洞引擎，前往终章行星。黑洞引擎由等离子引擎与[最终能源核心](#最终能源核心)装配获得。

最终装配完成时，制作台解体，原位置留下黑洞引擎。作用范围限于制作台本体，周围方块、实体与引擎成品保持完整。

### 引擎索引

离子引擎 → 亚光速引擎 → 等离子引擎 → 黑洞引擎。升级消耗上一代引擎。

| 引擎 | 获取或制造 | 用途 |
| --- | --- | --- |
| 离子引擎 | [木卫一](#木卫一)地牢 | 六阶火箭改装 |
| 亚光速引擎 | [Eris](#eris)图纸解锁制造 | 七阶火箭与常规系外航行 |
| 等离子引擎 | 亚光速引擎升级 | 九阶飞船与开普勒航行 |
| 黑洞引擎 | 等离子引擎与最终能源核心装配 | 十阶飞船与终章航行 |

## 装备

### 氧气罐

氧气罐储存随身氧气，放入氧气装备栏的罐位使用。氧气系统包括氧气面罩、氧气装备和储有氧气的氧气罐。

| GC 氧气罐 | 容量 |
| --- | --- |
| 轻型 | 900 |
| 中型 | 1800 |
| 重型 | 2700 |

容量为储氧数值。

## 任务系统

### 公共团队

服务器玩家共用一个公共团队，任务进度在团队内共享。

### 任务检测

| 目标类型 | 完成条件 |
| --- | --- |
| 物品 | 持有指定数量；完成检测后保留物品 |
| 探索 | 实际抵达指定目的地 |
| 战斗 | 有效击杀指定目标 |

物品目标接受制作、交易、采集等来源。任务采用无奖励模式。
