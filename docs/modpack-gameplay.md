# 整合包玩法定稿

## 一、发展路线

地球与月球 → 火星与三级火箭 → 四至六阶太阳系探索 → 七阶火箭与常规系外探索 → 九阶多人飞船与开普勒 → 十阶飞船与终章行星。

| 阶段 | 探索与制造 |
| --- | --- |
| 一至三阶 | 使用 GC 基础火箭体系，建立供电、燃料、供氧和材料加工能力，探索月球、火星及后续目的地 |
| 四至六阶 | 使用 GS 火箭与装配体系，探索太阳系主星和卫星，取得图纸、特色材料与离子引擎 |
| 七阶 | 制造新的七阶材料与火箭，使用亚光速引擎进入常规系外探索 |
| 九阶 | 使用等离子引擎制造多人飞船，前往开普勒 |
| 十阶 | 以等离子引擎和最终能源核心制造黑洞引擎，完成十阶飞船，前往终章行星 |

## 二、太阳系天体

| 天体 | 采用版本 | 卫星与归属 |
| --- | --- | --- |
| 水星 | GS、EP 两颗地表同时保留 | 两颗分别显示，EP 地表带来源标记 |
| 谷神星 | GS、EP 两颗地表同时保留 | 两颗分别显示，EP 地表带来源标记 |
| 火卫一 | GS | 不保留 EP 火卫一 |
| 木星 | EP | 木卫一、木卫二、木卫三、木卫四采用 GS，归属 EP 木星；不保留 EP 对应四颗卫星 |
| 土星 | EP | 土卫二、土卫六采用 GS，归属 EP 土星；不保留 EP 土卫六 |
| 天王星 | EP | 保留 GS 天卫五，归属 EP 天王星 |
| 海王星 | EP | 海卫一采用 EP，不保留 GS 海卫一 |
| 冥王星 | EP | 不保留 GS 冥王星地表 |
| Eris | EP | 保留独立地表 |

同一天体的重复展示节点只保留一个。GS 卫星改挂 EP 主星后，保留自身的地表、矿物和结构。

## 三、图纸与解锁

| 探索地点 | 关键产出 | 解锁用途 |
| --- | --- | --- |
| EP 水星地牢 | GS 四阶火箭图纸 | 四阶火箭；该图纸的唯一来源 |
| EP 木星地牢 | GS 五阶火箭图纸 | 五阶火箭；该图纸的唯一来源 |
| EP 土星地牢 | GS 六阶火箭图纸 | 六阶火箭；该图纸的唯一来源 |
| GS 木卫一地牢 | 离子引擎 | 六阶离子改装；引擎奖励只提供离子引擎 |
| EP 海王星地牢 | 特殊制造台图纸 | 制造七阶材料加工设备 |
| EP 冥王星地牢 | 七阶火箭图纸 | 七阶火箭制造 |
| EP Eris 地牢 | 亚光速引擎图纸 | 亚光速引擎制造与升级 |

特殊制造台图纸用于制造设备，设备造出后可反复加工材料。图纸解锁与实际制造资格对应，旧许可和旧配方不提供绕过入口。

## 四、引擎与飞船

离子引擎 → 亚光速引擎 → 等离子引擎 → 黑洞引擎。升级时使用上一代引擎作为投入。

| 引擎 | 对应发展阶段 | 用途 |
| --- | --- | --- |
| 离子引擎 | 六阶 | 六阶火箭的动力改装 |
| 亚光速引擎 | 七阶 | 支持常规系外航行 |
| 等离子引擎 | 九阶 | 制造九阶多人飞船，前往开普勒 |
| 黑洞引擎 | 十阶 | 制造十阶飞船，前往终章行星 |

等离子引擎保留一个空核心位置。空位不影响九阶飞船正常航行，也不影响首次前往开普勒。

最终能源核心使用蓝、红、紫、黄、绿五种钻石与铂制品，五色均为必需材料。取得核心后补全空位，以等离子引擎为基础制造黑洞引擎。

黑洞引擎完成最终装配时，制作台炸开，原处留下引擎成品。演出不破坏周围方块、不造成伤害，也不损失成品。

## 五、材料、设备与内容取舍

| 内容 | 采用规则 |
| --- | --- |
| 星球材料 | 保留的材料均接入实际加工、制造或升级，后段星球特色材料参与后续发展 |
| 七阶材料 | 从保留星球的实际产出重新设计，不沿用原 EP 七阶板材链 |
| 获取阶段 | 首次七阶制造使用七阶前可得材料；九阶制造不使用开普勒材料；最终能源核心不使用终章材料 |
| 同类材料 | 重复金属统一物品与加工关系；不同星球可以保留同类矿源 |
| 独立材料 | EP 水晶与 GS 未知晶体分别保留；EP 火山锭与 GS 木卫一火山石分别保留 |
| 加工与补给设备 | 有加工、供电、供氧、精炼、加注、净水等实际作用的设备保留 |
| EP 普通工具与护甲 | 16 套材质的普通工具、武器和护甲不注册，包括五色钻石装备；原材料保留 |
| 原 EP 火箭体系 | 原各阶火箭、专用部件、专用板材、旧火箭图纸和原制造路线退出；新火箭按配件设计选择性复用素材与部件 |
| 地形与生态 | 保留星球的地形、矿源、建筑材料和生态内容随星球保留 |
| 地牢功能 | 保留钥匙、宝箱、Boss 与地牢结构，关键奖励按图纸路线安排 |

## 六、公共进度与任务书

| 项目 | 采用规则 |
| --- | --- |
| 团队 | 服务器玩家使用同一个公共团队，共享任务进度 |
| 任务目标 | 以获得物品、抵达目的地和有效击杀为主 |
| 物品检测 | 默认检测持有，不消耗物品，不限定制作、交易或采集来源 |
| 任务奖励 | 不配置任务奖励 |
| 实际解锁 | 火箭制造、航行与核心资格由实际装备、图纸和载具条件决定 |

## 七、配置与版本

正式配置随整合包版本一起使用。后续调整在正式配置上逐项维护，不用原版配置、旧备份或其他实例配置整份替换。

玩法定稿采用当前检查通过的版本，后续调整同步更新对应条目。
