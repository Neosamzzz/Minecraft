由[基础太阳能蒸发室](#基础太阳能蒸发室)加工钾盐碎片获得。与碘盐一起投入化学注入器，产出碘化钾。

### 动力部件

#### 离子引擎

| 属性 | 内容 |
| --- | --- |
| 获取地点 | [木卫一](#木卫一)地牢 |
| 适用载具 | [GS 六阶火箭](#gs-六阶火箭) |
| 安装设备 | GS 改装台 |

#### 亚光速引擎

将离子引擎与Eris地牢的亚光速引擎图纸投入[引擎升级台](#引擎升级台)，加工一个亚光速引擎。它是七阶总装和等离子引擎升级的消耗材料；七阶没有引擎改装项，成品不保存亚光速引擎状态。

#### 等离子引擎与黑洞引擎

亚光速引擎与巴纳德C1地牢取得的等离子引擎图纸在引擎升级台加工为等离子引擎，用于九阶总装。等离子引擎与最终能源核心加工为黑洞引擎，用于十阶总装。

最终能源核心在 GS 装配机使用蓝、红、紫、黄、绿钻石各1枚和压缩铂4枚制造，原料来自开普勒。

## 设备

### 加工设备

#### 星际装配机（材料制造台）

在GS装配机中投入六阶强化板×4、GS现代晶圆×2、GC致密钢板×2和材料制造台图纸×1制造。

右键打开九宫格加工界面，原料按 JEI 显示的对应格子放置，未使用的格子留空，不能将同一种原料拆到其他格子。右侧取出成品，电池槽接受 FE 和 GC 电力物品；进电面为放置时玩家所见的左面。储电上限50000 FE，每批200 tick、每 tick消耗40 FE，正常运行约10秒、共8000 FE。加工进度与电量随存档保存，下方漏斗提取成品，其余方向输入原料。开启 Jade／Hwyla 的电量提示后可查看储电量与容量。

| 成品 | 每批原料 | 每批产量 |
| --- | --- | --- |
| 钨基复合板 | 六阶强化板×3、EP钨板×2、EP钯板×1、EP火山锭×1 | 2 |
| 隔热衬层 | EP碳板×2、GS未知晶体×1、冻结氮×4、GS塑料×2 | 2 |
| 深空航电组件 | GS现代晶圆×1、EP白宝石晶圆×1、EP蓝宝石×2、EP锌板×1、EP水晶板×1 | 1 |
| 锌基连接组件 | EP锌板×4、GC铜板×2、GS空白模块×1 | 2 |

七阶后还可加工紫晶锭与紫晶复合组件，完整加工关系见[制造路线](../project/NewEarth/items/route-manuscript.md#七阶系外探索与九阶制造)。

#### 引擎升级台

制造材料与星际装配机相同，图纸改用天王星的引擎升级台图纸。不需要供电，每批200 tick（正常运行约10秒）。上方槽放引擎，下方槽放对应升级材料，右侧取出成品；对调输入不加工。支持离子→亚光速→等离子→黑洞三次升级，原料见[动力部件](#动力部件)。黑洞引擎完成时台体散开，库存和成品掉落，周围方块与玩家不受爆炸伤害。

#### 星际组装台与拆解台

两种设备均在 GS 装配机使用钨基复合板×4、深空航电组件×1、锌基连接组件×2、压缩钢×2制造。

星际组装台用于七／九／十阶总装，每槽放一件部件，中央放独立动力材料，右上放图纸或控制面板。无需供电，默认720 tick（36秒），随 GS 火箭装配速度系数调整；完成时消耗输入，加工进度随存档保存。

拆解台将火箭放入右侧成品槽，立即按总装用量向对应零件槽返还部件、动力材料、图纸或控制面板及货箱；输出格须为空或可继续叠放相同物品。支持七／九／十阶，不支持六阶。

#### 基础粉碎机

用于将钾盐矿加工为[钾盐碎片](#钾盐碎片)。

| 项目 | 内容 |
| --- | --- |
| 制造材料 | 致密汞板 ×4、铁砧 ×2、活塞 ×3 |
| 加工输入 | 钾盐矿 ×1 |
| 加工输出 | 钾盐碎片 ×3 |

#### 基础太阳能蒸发室

用于从[钾盐碎片](#钾盐碎片)中提取[钾](#钾)。

| 项目 | 内容 |
| --- | --- |
| 制造材料 | GC 基础太阳能板 ×4、致密汞板 ×3、水星石砖 ×2 |
| 加工输入 | 钾盐碎片 ×12 |
| 加工输出 | 钾 ×1 |

## 载具

### 火箭

#### GS 六阶火箭

采用GS火箭装配机制造，动力模块仅支持[离子引擎](#离子引擎)。

前往 Eris 必须在 GS 改装台实际安装离子引擎；仅持有模块不能通过准入。卸下时返还模块并恢复改装槽位，回收火箭保留离子引擎状态。

| 六阶目的地 | 版本 |
| --- | --- |
| [海王星](#海王星)及海卫一 | EP |
| [冥王星](#冥王星) | EP |

#### 七阶火箭

GS装配机制造鼻锥、箭身、推进器、助推器和尾翼；星际组装台总装。将鼻锥×1、箭身×2、推进器×1、助推器×2、尾翼×2放入对应槽位，右上放冥王星七阶图纸×1，中央动力槽放亚光速引擎×1。当前共用总装配方输出标准零货箱规格，尚未提供货箱输入槽。

七阶沿用 GS 普通点火流程，使用 GS 高级发射平台；常规系外目的地包括比邻星b、巴纳德C／C1和鲸鱼座τ f，最低七阶。七阶及以上有效飞船可直接通过 Eris 准入。

物品与世界实体直接复用 EP 原七阶模型，世界实体单独调整比例。

#### 九阶与十阶六座飞船

九阶配件在 GS 装配机由七阶配件及紫晶材料升级，再以控制面板和等离子引擎在星际组装台总装。九阶可前往开普勒。拆解九阶后，使用同套结构件与控制面板，把中央动力改为黑洞引擎即可组装十阶。

两阶均可放置于完整 GC 火箭发射台或 GS 高级发射台，提供六个乘坐位置；驾驶员回收船体与货物，乘员不重复取得船体。货箱规格与燃料状态随飞船保存，已在船上的玩家右键离开自己的座位。

十阶升空后正常使用星图选择目的地，配置发射控制器时沿用指定航线。特拉尔斯-9 要求十阶飞船；首次抵达播放、同船等待与下降规则见[终章维度](../project/NewEarth/dimension/README.md#抵达流程)。生存全流程、实际多人航行和保存重进仍需游戏内验收。

## 装备

### 供氧装备

#### 氧气罐

氧气罐储存随身氧气，装入氧气装备栏的罐位使用。供氧系统由氧气面罩、氧气装备和储有氧气的氧气罐组成。

| GC 氧气罐 | 储氧容量 |
| --- | --- |
| 轻型 | 900 |
| 中型 | 1800 |
| 重型 | 2700 |

### 宇航服

GS 普通宇航服与轻型宇航服穿戴于护甲栏。头盔、胸甲、护腿、靴子四件齐全时提供 EP 气压与辐射防护，两种型号可按部位混穿。缺少任一部位会恢复 EP 环境暴露处理。

宇航服防护与供氧、温控分别配备。已有的 EP 辐射累积可使用抗辐射饮料与辐射消除装置处理。

### 温控装备

#### GS 三级温控装备

温控强度为3，包含头部、上身、腿部和足部四件，分别穿戴于温控装备栏的对应位置。手持装备右键可穿入空置的对应温控槽位。EP 木星、土星使用完整三级温控四件套。

#### GS 四级温控装备

温控强度为4，包含头部、上身、腿部和足部四件。穿戴位置与操作同[GS 三级温控装备](#gs-三级温控装备)。EP 天王星、海王星、海卫一、冥王星与阋神星使用完整四级温控四件套。
