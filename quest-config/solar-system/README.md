## 完成与布局

- 物品目标数量为 1，不消耗物品，不限定制作来源，忽略 NBT。只有颜色、罐内余量、电量、同级货舱等允许差异时忽略元数据；图纸、机器、HDP 和材料严格匹配子项。
- 维度条件使用实际维度 ID；月球与火星 Boss 使用击杀条件，目标均为一次。历史击杀不补记。
- 所有目标独立记录，不使用依赖锁。布局按供给、加工、制造和探索分组，重要节点放大为方形。当前不画会影响完成资格的依赖连线，避免旧存档缺少早期材料记录时被阻断。
- 支线使用 `optional`，不成为火箭推进门槛。外太阳系的到达目标计入本章进度，但不锁住其他章节。
- 任务进度沿用当前 FTB 团队。玩家共享完成不等于各自已穿戴装备、设备通电或据点可用。
