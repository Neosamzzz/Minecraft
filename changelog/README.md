# 开发记录

所有"改了什么"的记录统一放在这里。这个仓库同时承载几条开发线，各自的版本历史分散在源码和测试目录里很难找，统一收口到本目录。

| 记录 | 内容 | 当前版本 |
| --- | --- | --- |
| [gslc.md](gslc.md) | GSLaunchCompat 补丁的版本历史（发射控制器权限、遥感显示器、地图与时钟） | 1.4.8 |
| [modpack.md](modpack.md) | 整合包基线：模组清单、版本、配置入口 | — |
| [ftb-quests.md](ftb-quests.md) | FTB Quests 相对上游的本地改动 | 无改动 |

## 用法

- **改了什么写在对应记录里。** 新增版本时在文件末尾追加条目，不要改写历史条目。
- **记录按"改动 / 影响面 / 验证状态 / 是否需要服务端同步"四段写**，测试细节仍留在对应测试目录，这里不重复。
- 游戏内的实测结论属于玩法资料，写在 `docs/research/` 下，不写在这里。

## 与其他文档的关系

- `GalaxySpace/tests/` 下是各补丁的构建方式和验证手段，读更新记录时按需跳转。
- `docs/` 是 FTB 支线的资料区，见 [docs/README.md](../docs/README.md)。
