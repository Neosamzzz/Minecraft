# FTB Quests 本地改动

上游：[FTBTeam/FTB-Quests](https://github.com/FTBTeam/FTB-Quests) 分支 `1.12`，导入提交见 [upstream.json](../upstream.json)。

核对日期：2026-11-02。本机开发包 **1202.9.3** 已加入熟人服公共团队、关闭游戏内任务编辑并精简无奖励详情。1202.9.2 的完整构建与 20 项隔离检查、1202.9.3 的完整构建已有记录，实际双人联机与 GUI 验收未完成。

代码、六章任务与正式玩家说明书已统一并通过 PR #15 合入 `main`。代码保留 `f2386a4` 的 1202.9.3 实现，文档与配置合入原文档线成果；不再提供基于 1202.9.1 的独立 FTB 文档构建入口。下方保留历史版本记录，游戏观察见[玩法详解](../docs/research/planet-gameplay-guide.md#十三2026-11-02-运行日志补记)。

## 相对上游的改动

| 项 | 改动 | 原因 |
| --- | --- | --- |
| 依赖来源 | `maven.latmod.com` 改为 Curse Maven 固定项目编号和文件编号 | 原仓库 TLS 握手失败；旧 CurseMaven 插件会把网页存成 JAR，导致兼容模块缺类 |
| 资源下载 | `gradle/legacy-assets.gradle` 改用 Mojang 官方 HTTPS 地址，并校验每个文件的大小与 SHA-1 | 旧 ForgeGradle 走 HTTP 且忽略下载失败 |
| 编译编码 | 固定 UTF-8 | |
| 构建入口 | 并入根目录 `tools/build.py` | |

细节见 [FTB-Quests/DEVELOPMENT.md](../FTB-Quests/DEVELOPMENT.md)。

`FTB-Quests/README.md` 是上游自带的 CurseForge 徽章页，未做改动；本仓库的构建与开发说明以 `DEVELOPMENT.md` 为准。

## 后续注意

- 更新上游时要先审阅本地改动，避免直接覆盖构建配置。
- 后续修改团队与任务相关代码时继续追加条目，写清改了哪个类、为什么、影响哪些行为，并区分已提交、已打包与待实测。
- 任务书内容本身不属于本文件，见 [docs/README.md](../docs/README.md)。

## 1202.9.1 / 2026-11-02 公共团队最小版

- **改动**：`SharedTeamManager` 在 Library 加载完成后选择或创建公共团队，在任务数据同步前自动归队；选队 ID 由 `FTBQuestsWorldData` 随存档保存。迁移不调用会删除空队的 `removeMember`。多队有数据或指定队不存在时停止自动接管并报日志。`SharedTeamConfig` 提供默认启用开关与既有团队 ID。
- **影响面**：服务端拦截队伍变更命令并隐藏 Library 的成员、关系、退队与转让 action；客户端收到公共团队模式后隐藏“我的组”，任务书添加编辑模式开关并收起捐助按钮。FTB Quests 管理命令向全体玩家开放，Minecraft OP 和其他模组权限不变。普通奖励、可重复任务和任务检测继续用现有逻辑，不添加任务内容。
- **验证状态**：JDK 8 离线完整构建通过；`tests/shared_team` 探针使用实际 Library 团队和 Quests 数据检查选队、双人归队、重复归队、领奖数据保留、旧队保留、保存 ID、GUI action 拦截和禁用恢复。探针未启动完整 Forge 服务器、网络传输或 GUI 渲染；两人实际联机、界面画面和服务器重启后的落盘恢复待验。
- **是否需要服务端同步**：需要。任务同步包增加公共团队模式字段，两端均需更换为本地 `1202.9.1`，版本握手拒绝旧 `1202.9.0`。安装和回退方式见 [公共团队方案](../docs/ftb-shared-team-plan.md#最小版的使用方式)。

## 1202.9.2 / 2026-11-02 收起游戏内任务编辑

- **改动**：移除公共团队的编辑模式按钮；客户端与服务端在公共团队模式下都拒绝任务编辑，禁用编辑模式命令，旧的编辑状态不生效。
- **影响面**：玩家查看、完成、追踪任务与全服共享进度继续沿用。任务定义改由配置文件维护；关闭公共团队模式后可恢复上游编辑能力。
- **验证状态**：完整构建及 20 项隔离检查通过，新增服务端编辑能力与编辑命令拦截检查；实际 GUI 画面、多人联机待验。
- **是否需要服务端同步**：两端都需更新到 `1202.9.2`，避免旧客户端残留编辑按钮。

## 1202.9.3 / 2026-11-02 精简无奖励任务详情

- **改动**：无可见奖励时隐藏奖励标题、占位文字和中间竖线，任务目标使用整行宽度；有奖励时仍显示原有双栏，非公共团队的编辑模式仍保留添加奖励入口。补齐前置与后续任务导航的中文提示。
- **影响面**：仅任务详情界面显示与中文翻译，完成判定、前置关系、进度和奖励数据不变。
- **验证状态**：完整构建通过；实际游戏画面待确认。
- **是否需要服务端同步**：本次未改通信格式，可与 1202.9.2 通信；建议客户端和服务端统一使用 1202.9.3，便于版本管理。

## 2026-11-02 统一 FTB 开发分支与重新部署

- **改动**：将公共团队代码线与文档、六章任务线合并为 `codex/ftb-public-team`。保留 `f2386a4` 的全部 Java、版本与探针实现，解决五个文档冲突，移除源码仍为 1202.9.1 的过期说明。代码行为未新增，模组版本保持 1202.9.3。
- **影响面**：同一分支可构建当前代码并取得六章、60 个目标、0 奖励的配置和正式玩家说明书。旧文档分支停止独立维护。原新地球物品线与维度线继续独立开发。
- **验证状态**：JDK 8 离线完整构建通过；公共团队探针 20 项通过。重新部署本机 JAR 与六章任务定义，文件哈希一致，保留全局任务设置和团队数据。未启动游戏，界面、多人同步及保存验收待补。
- **是否需要服务端同步**：使用这套内容的服务端应同步 1202.9.3 JAR 和对应任务定义。本次只部署本机客户端实例，没有访问或改写远程服务器。
